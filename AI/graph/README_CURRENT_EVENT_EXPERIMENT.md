# 현재 기업 사건 정제와 추가 기사 GNN 대조 실험

2026-09-15. `news_current_events_20260915_v2` 연구 실험이다. 사용자가 남은 사건 주체·시점
정제 및 영향도 개선 작업의 계속 진행을 요청했다. 기존 서비스 모델은 자동 교체하지 않는다.

## 고정한 계약

- 기존 29,827개 기사와 845,742개 기사×기업 가격 정답은 원본 파일에 보존한다.
  새 실험의 pairs에는 기존 행 전체를 같은 순서로 복사한 뒤 새 학습 행만 붙인다.
- 평가 모집단은 원래 직접 val 4,813쌍이다. 종전 본문 위생 검사에서 유지된 4,743쌍을
  예측하며 70쌍의 미응답도 원래 모집단 점수에서는 오답으로 센다. 새 사건 규칙으로 val를
  골라 쉬운 문제만 채점하지 않는다. 각 시장·기간에서 거래일을 동일 가중하고 네 셀을 평균한다.
- 기존 3분류 경계·강도 정규화·학습 기간 PCA64를 동결한다. 추가 학습 기사에 맞춰
  검증 정답을 재정의하지 않는다. 신규 기사의 인코더도 기존 동결 모델을 사용한다.
- 발행시각 복원 후보를 주가 정렬에 적용하지 않는다. 기존 보수적 `available_at` 이후 첫
  종가에서 +1/+3세션 수정종가 로그수익률에서 실제 시장 지수 로그수익률을 뺀다.
  즉시 뉴스 반응·인과 영향의 정답이라는 뜻은 아니다.
- 새 학습 대상으로 연결하기 전에 이용 가능 시각까지 유한하고 양수인 수정종가가 한 번 이상
  관측됐는지 확인한다. 이는 관측 이력 조건이지 과거 법인·상장 이력의 인증이 아니다.

## 사건 규칙과 독립 검토

`current_event_gate.py`는 기업별 주어·행위 구조, 원문 인용, 과거 시점·자료 인용·고객 매출
제외 사유를 반환한다. 제목/본문 앞 2,400자와 700자 이하 문장에서 보수적으로 선택한다.
지원하지 않는 표현, 대명사, 인용된 타 기업 사건, 불확실한 전망은 보류할 수 있다.
수익 배분 계약은 실적이 아닌 계약으로 분류한다. 모든 결과는 규칙 후보이며 사람 정답이 아니다.

새 26,820개 후보와 기존 학습 기사에 같은 사건 규칙을 적용한다. 정제 후에도 역사적 본문
수정이나 기업 식별의 정확성을 인증할 수 없으므로 약한 규칙으로 선택한 연구 자료임을 유지한다.
별도 에이전트가 가격·예측과 규칙 구현을 보지 않고 60개 유지 표본의 기사 문맥을 검토한다.
이 검토도 AI 보조 판정이며 사람 정답이나 전체 모집단 정밀도를 대신하지 않는다.

첫 규칙에서 ‘롯데는 지난해 … 삼성SDI 화학사업 …를 인수했다’의 괄호 안 기업을
현재 인수 주체로 잘못 잡는 버그를 발견했다. 첫 준비 결과 4,173기사/4,390쌍은
`news_current_events_20260915`와 당시 코드 스냅샷으로 보존하고 학습하지 않았다.
v2는 한국어 주어 표지·괄호 안 대상·비실적 과거 시점 제외를 보강했다. 60개 표본은
이 수정 이후 개발 자료로 취급한다. 이전 84개 ID와 겹치지 않는 새 유지 기사 24개를
국내/해외·연도별 2개씩 해시로 선택해 별도 AI 검토한다. 새 검토에는 자동 근거를 보여주지
않으며 그 결과로 v2 규칙을 추가 조정하지 않는다.

## 그래프와 학습 비교

연도 시작 이전에 이용 가능했던, 사건 규칙을 통과한 학습 기사들의 공동 언급으로 그래프를
다시 만든다. 같은 시장의 전년도 수정수익률 상관(중복 관측 60회 이상)도 사용한다.
검증·테스트 기사, 미래 가격, 과거 정제 여부가 확인되지 않은 기존 관계 문장, 지분·업종
엣지는 이 실험 그래프에서 제외한다. 원래 서비스 그래프의 모든 관계 유형을 대체하는 번들이 아니다.

세 조건에 같은 새 그래프를 사용하고 각 3시드 GATv2를 학습한다.

| 조건 | 학습 기사 | 뉴스 입력 |
|---|---|---|
| clean_old | 기존 학습 중 사건·가격 이력 조건을 통과한 기사 | 기업별 동결 문맥/금융 감성 |
| expanded | clean_old + 새로 정제한 기사 | 같은 인코더/투영 |
| no_content | expanded와 동일 | 문맥·감성 0, 기업/시장/언급/그래프는 유지 |

clean_old도 새 기사가 포함된 공통 그래프를 쓴다. 따라서 expanded와의 차이는 그 그래프가
주어진 상태에서 지도학습 기사 추가의 효과이며, 새 데이터 전체의 효과를 완전히 분리한 비교는 아니다.
기존 GNN, 다수 클래스, 종목별 빈도 기준선도 함께 보고한다.
하이퍼파라미터는 기존과 동일: 30에폭 상한, patience 6, batch 24, hidden 64,
dropout .15, AdamW lr .0008/weight decay .001, 직접 기업 CE+Huber.

## 검증과 결과

`verify_current_events.py --data-only`는 학습 전 데이터 격리·라벨·그래프·특징 정합성을 검사한다.
학습 후에는 CPU 체크포인트 재생, 앙상블 평균, 신규 인코더 재생, 거래일 HAC 및 Holm을 재계산한다.
비교는 재사용한 2023 검증 구간이므로 탐색 결과다. 최종 일반화 주장은 새로운 후속 기간에서 확인해야 한다.
시각 원천 계약과 과거 법인 식별의 남은 한계는 `NEWS_EVENT_DATA_READINESS.md`에 정리했다.

데이터 준비와 학습 전 전체 검증은 완료했다. 준비 시간 117.9초.

|---|---:|---:|
| 정제된 기존 학습 | 409 | 420 |
| 새로 추가한 학습 | 3,493 | 3,621 |

추가 가능 후보 26,820개 중 23,327개는 사건 규칙 또는 과거 가격 이력/유효 정답 조건을
통과하지 못했다. 학습용으로 지나치게 범위를 좁혀 유용한 뉴스를 놓칠 수 있으며,
조건을 통과한 기사만 별도 val로 골라 점수를 올리지 않았다.
새 연속 가격 정답 7,242개를 독립 재계산한 최대 차이는 3.12e-15였다.
원래 845,742쌍과 29,827기사의 식별·시각, 평가 4,743/4,813쌍, 분류 경계·투영은 보존됐다.
연도별 그래프 엣지는 644/668/680/700/728/768/788개다. 2023년 788개 중
공동 언급 32개, 가격 상관 756개로 여전히 가격 관계 비중이 크다.

새 블라인드 AI 검토 24건은 현재 사건 지지 18, 보류 4, 미지지 2였다.
미지지 두 건은 Amazon의 과거 실적 회고와 타사 계약 기사 속 과거 인수 설명이었다.
실적 발표 전 프리뷰 및 시점이 불분명한 사례도 남는다. 원문 숫자 모순 두 건도 별도 기록했다.
이 수치는 24건의 AI 의미 판단이며 사람 정답 정확도·전체 후보 정밀도·주가 예측 정확도가 아니다.
기존 60개 개발 표본과 모집단/선택 방식이 다르므로 두 비율을 빼서 정밀도 개선이라고 하지 않는다.
검토 기록은 `artifacts/current_event_holdout_review_20260915/ai_review.json`에 있다.

3조건×3시드, 총 9개 GAT 학습을 완료했다(190.8초). 3시드 확률을 평균한 결과다.

| 모델 | 원래 4,813쌍 기준 정확도 | 유지 4,743쌍 기준 정확도 |

원래 모집단에서 expanded는 clean_old보다 +2.51%p, no_content보다 +0.74%p지만
기존 GNN보다 −1.43%p다. **65% 목표 미달이며 기존 모델을 유지한다.**
학습 기사 정제가 가격 예측 개선을 보장하지 않음을 확인한 연구 결과다.
기존 모델 대비 전체 우위 또는 뉴스 내용의 추가 예측력을 입증했다고 표현하지 않는다.

유지 모집단에서 거래일 HAC(5/20일)·각 20개 비교의 Holm 보정 후,
expanded 대 no_content 및 대 original의 모든 시장·기간 셀은 p≥.05였다.
NASDAQ 1일에서 clean_old 대비 +6.09%p는 두 lag에서 유의했지만,
모든 새 기사 정보를 공유한 그래프 하에서 작은 정제 학습 집합에 기사를 추가한 비교다.
이 결과를 기존 GNN 대비 개선이나 새로운 독립 테스트 성과로 바꾸지 않는다.

원천 시각 계약·당시 법인 식별·완전한 사건 품질은 여전히 미확인 부분이 남는다.
기존 검증 구간을 반복 활용했으므로 후속 모델 채택에는 새 평가 기간이 필요하다.
새 서비스 번들 생성·운영 연결·기존 모델 교체·커밋·push/MR은 수행하지 않았다.

- 3시드 평균·지표 24개 재계산: 최대 차이 5.55e-17.
- 거래일 HAC 비교 40개와 lag별 Holm 20개 재계산: 최대 차이 4.44e-16.
- 모든 신규 정답, 원래 평가 모집단/입력 해시, 그래프 모든 엣지를 다시 확인했다.

개선된 입력 정제 코드와 재현 가능한 연구 체크포인트는 남겼지만, 이 검증은 실행 정확성을
