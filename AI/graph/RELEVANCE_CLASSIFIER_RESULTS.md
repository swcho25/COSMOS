# 뉴스·기업 관련성 분류기 학습 및 새32건 비교

2026-09-17 KST. **파일럿 학습과 비교를 완료했지만, 이번 분류기는 자동 선별에 적용하지 않는다.**
개발자료에서 자동 결정 조건을 만족하지 못해 두 방향을 비활성화했고, 새32건에서도 전건 보류했다.
기존 LLM보다 유용한 기사를 더 놓쳤다. 1,000건이나 전체189,101건의 자동 선별로 확대하지 않았다.

## 무엇을 만들었나

사용자가 검수한100건(채택69/제외31)을 원문·선택 기록과 함께 검증하고,
학습80건(55/25)과 개발20건(14/6)으로 나눴다. ID·URL·정규화 본문 그룹의 교차중복은0이다.
이 선택들은 AI 추천을 보고 내린 판단이며 독립적인 사람 정답집은 아니다.

기업명·제목·본문을 기존 multilingual MiniLM encoder에 입력해 전체 토큰의 특징을 계산했다.
encoder는 동결하고, 768차원 특징에 채택/제외 로지스틱 회귀를 학습했다.
**작은 선형 분류기를 실제 학습한 것이며, 언어 모델 전체나 CrossEncoder를 미세조정하지 않았다.**
관련 파일과 재현 명령은 `README_RELEVANCE_CLASSIFIER.md`에 있다.

문장 생성이 없어 JSON 생성 실패는 발생하지 않는다. 하지만 출력 형식 문제가 없어지는 것과
경제적 관련성을 올바르게 판정하는 것은 별개이며 이번 결과는 후자를 충족하지 못했다.

## 학습에서 확인한 한계

개발20건의 클래스 균형 log loss로 C를 선택했다.

| C | 개발 균형 log loss — 작을수록 좋음 |
|---|---:|
| 0.1 | 0.691087 |
| 1.0 | 0.709875 |
| 10.0 | 0.790305 |

C=0.1을 선택했다. 개발 score 범위는0.4582~0.5775였다.
채택 임계값은 개발자료에서 적어도3건을 맞게 채택하면서 오채택0건,
제외 임계값은 적어도3건을 맞게 제외하면서 오제외0건이어야 한다는 사전 규칙을 사용했다.
어느 쪽도 조건을 충족하지 못했다. 새 결과를 본 뒤 규칙이나 임계값을 낮추지 않았다.

개발20건을 C와 임계값 선택에 함께 사용했고, 정답에 보류 클래스가 없다.
따라서 score를 정확도·주가변동 가능성·보정된 확률로 해석할 수 없다.
작은 표본, 평균/최대 풀링으로 인한 주체·역할 정보 손실, 레이블 기준의 불확실성이
제약일 수 있지만, 이번 실험만으로 각각의 원인 기여도를 분리하지는 못했다.

## 새 기사32건 비교

정책·모델을 동결한 뒤 기존 검토654기사와 가격예측 val/test11969기사를 제외했다.
국내 출처16·해외 출처16, 2020~2022년, 본문200~6000자에서 고정 해시로 선택했다.
ID·본문·URL 중복이 없으며 제목과 본문을 바꾸지 않았다.

두 별도 AI 검토자가 모델 출력 없이 각각16건의 전체 원문을 읽었다.
참고판정은 **채택19 / 제외9 / 보류4**였다. 이것은 독립적인 **AI 참고판정**이며,
사람 정답이나 실제 주가 영향 검증이 아니다.

| 항목 — 전체32건 기준 | 기존 Qwen 2단계 v1 | 새 분류기 |
|---|---:|---:|
| 자동 채택 | 9 | 0 |
| 자동 제외 | 0 | 0 |
| 보류 | 23 | 32 |
| 참고 채택19건 중 채택 | 9 | 0 |
| 참고 채택19건 중 누락 | 10 | 19 |
| 참고 제외9건 중 오채택 | 0 | 0 |
| 참고 보류4건 중 채택 | 0 | 0 |
| 참고 채택19건 중 오제외 | 0 | 0 |
| 참고판정과 선택 일치 | 13/32 | 4/32 |
| 형식·길이 검증 실패 | 0 | 0 |
| 개별 기사 처리시간 합 | 165.2001초 | 0.8909초 |

처리시간은 모델 로딩·파일검증·학습을 뺀 각 행의 처리시간 합이다.
분류기의 경우 주로 encoder 특징 계산 시간이며 전체 wall time 비교가 아니다.
전건 보류했으므로 짧은 처리시간을 유효한 자동 선별의 성과로 내세우지 않는다.

기존 LLM의 채택9건은 이번 AI 참고와 모두 일치했지만, 참고 채택19건 중10건을 놓쳤다.
작은 표본에서 오채택0건이라고 전체 데이터에서 정밀도100%를 주장할 수 없다.
새 분류기는 전건 보류 기준선과 동일하다. 오채택을 늘리지 않았더라도 관련 기사를
하나도 선택하지 못했으므로 개선이 아니다.

참고판정과 기존 LLM이 함께 채택했지만 분류기가 보류한 사례:

- Microsoft의 Activision 인수 발표: 인수 및 구독 게임 사업과의 원문상 연결.
- 삼성전자의 TV 수요 감소 기사: 생산 가동률과 제품 대응 계획.
- 한국조선해양의 원유운반선 수주: 계약 금액·척수·인도 일정.

이 사례들은 오류 분석용 AI 참고이며 확정 GNN 학습 정답으로 자동 편입하지 않았다.

## 이후 작업 판단

이번 **80건 학습 + 동결 임베딩 + 선형 분류** 조합의 실패를 확인했다.
모든 관련성 분류기가 불가능하다거나 GNN 자체가 실패 원인이라는 결론은 아니다.

다음 개선은 대량 기사에 현재 판정을 붙이는 작업보다, 기업별 사건 주체와 경제적 연결 경로를
명확히 구분한 예시를 추가 확보하는 데 초점을 둔다. 실적·수주·인수의 관련 사례와
과거 직장·인물 약력·그룹 내 타 법인·기업 나열의 어려운 제외 사례를 함께 준비해야 한다.
정답 기준을 먼저 고정하고 일부를 사람이 AI 추천 없이 재검토한 뒤,
본문과 대상 기업의 관계를 학습하는 모델의 미세조정 후보를 별도 평가할 수 있다.
추가 데이터만으로 개선이 보장되지는 않는다. 이번에 사용한32건은 다음 새 평가로 재사용하지 않는다.

이번 작업에서는 GNN 재학습·번들 교체·서비스 및 HDFS 변경·commit/push/MR을 하지 않았다.
