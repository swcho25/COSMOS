# 기업 문맥 입력 대조 실험

기존 실패 분석에서 직접 기업명이 256토큰 밖에 있는 사례가 많아, 입력 구성만 바꾼
3시드 실험을 완료했습니다. **입력 포함률은 개선됐지만 예측력 개선은 확인하지 못했습니다.**
기존 모델 버전 `66c54ef0207b4783`을 유지하며 이번 모델로 교체하지 않습니다.

## 고정한 조건과 변경점

- 같은 기사 29,827건, 기사·기업 쌍 845,742개, train/validation/test 분할과 라벨.
- 같은 직접 언급 메타데이터, 후보, 과거 그래프, 회사 특징, GATv2 2층·hidden 64·dropout 0.15.
- AdamW 학습률 0.0008, weight decay 0.001, 배치 24, 최대 30에폭, patience 6, 시드 0/1/2.
- 방향 CE + 강도 Huber 손실과 기존 기사별 평균 비중 유지. 직접/간접 50:50 변경은 하지 않습니다.
- 같은 동결 임베딩·금융 감성 인코더, 임베딩 256토큰 / 감성 128토큰 한도.
- PCA는 기존처럼 64차원이며 **새 임베딩의 train 기사만으로 다시 적합**합니다.

변경하는 것은 인코더에 넣을 **원문 구간 선택**입니다.
제목에 최대 `min(48, 토큰 한도/4)` 토큰을 배정하고, 남은 공간은 직접 기업별 첫 매칭
언급 주변에 나눠 배정합니다. 원문 offset으로 연속 구간을 잘라 중복 구간을 합치며
다시 토큰화해 한도를 확인합니다. 문장을 생성하거나 사실을 덧붙이지 않습니다.
기업이 너무 많거나 재매칭되지 않으면 전부 포함하지 못할 수 있어 포함률을 따로 저장합니다.
주변 문맥은 토큰 창이므로 문장 전체나 부정·조건 표현까지 항상 보장하는 방식은 아닙니다.

여전히 **기사당 하나의 임베딩**을 모든 직접 기업에 주입합니다.
기업별로 다른 임베딩을 만드는 구조 변경은 이번 실험에 포함하지 않습니다.
감성 입력도 기존 제목+본문 앞 200자 대신 같은 문맥 선택 규칙을 사용하되 128토큰 한도는 유지합니다.

## 비교와 평가 범위

기존 GNN 및 기존 `no_content` 3시드 앙상블과 같은 validation 행으로 비교합니다.
`no_content`는 같은 차원의 텍스트·감성을 모두 0으로 만들고 나머지 입력은 같으므로,
이번 선택 규칙 변경에도 같은 대조군입니다. 기존 체크포인트를 재사용합니다.

체크포인트는 원래와 같이 validation 복합 손실로 선택합니다.
주 관심 지표는 2개 시장 × 2개 기간의 **직접 기업 거래일별 정확도 평균**입니다.
간접 기업 정확도와 전체 강도 MAE도 함께 보고합니다.
기술적 채택 후보 조건은 직접 평균 정확도가 두 비교군보다 높고,
간접 평균 정확도와 전체 평균 강도 MAE가 기존 모델보다 나빠지지 않는 것입니다.
이 조건만으로 통계적 우위나 미래 일반화를 주장하지 않습니다.

시장·기간·직접성별 두 비교군과의 정확도 차이에 HAC lag 5/20을 적용하고,
각 lag에서 24개 비교 전체에 Holm 보정을 적용합니다. 신뢰구간은 보정 전입니다.
모든 지표를 보고하며 특정 유리한 셀만 선택하지 않습니다.

기존 `fit_gat`는 validation으로 체크포인트를 고른 다음 모든 split의 예측을 계산해 저장합니다.
**이번 평가 코드에서는 새로운 test 지표를 계산하거나 열어보지 않습니다.**
validation도 개발에 사용한 데이터이므로 독립된 최종 성능 검증이 아닙니다.
모델이나 서비스 번들을 자동 교체하지 않습니다.

## 입력 포함률 실측

분모는 가격 라벨이 있는 직접 기사·기업 쌍이며, 매칭된 기업명 문자열이 임베딩 입력에
포함되는 비율입니다. 관련 사건의 모든 문맥이 포함된다는 뜻은 아닙니다.

| 구간·시장 | 기존 포함률 | 새 포함률 |
|---|---:|---:|
| train KOSPI | 58.30% | 98.66% |
| train NASDAQ | 51.60% | 99.93% |
| validation KOSPI | 59.17% | 98.54% |
| validation NASDAQ | 45.88% | 99.85% |

새 방식에서 원문 재매칭에 성공한 기업명은 임베딩·감성 입력 모두에 포함됐습니다.
재매칭되지 않는 기존 직접 기업 메타데이터는 임의로 수정하지 않았습니다.
Test 입력의 포함률도 파일에는 기록하지만, 새로운 test 예측 성능은 평가하지 않습니다.

## 3시드 검증 결과

특징 생성·학습·평가 904.5초(약 15분). 시드 0/1/2의 선택 epoch는 0 기준 5/2/6,
즉 6번째/3번째/7번째 에폭입니다. 각각 validation 복합 손실은
1.126060 / 1.126489 / 1.122743이었습니다. 시드별로 12/9/13에폭을 수행한 뒤 조기 종료했습니다.

아래는 **validation의 시장 2개 × 기간 2개에서 거래일별 정확도를 구한 뒤 네 셀을 동일 가중 평균**한 것입니다.
이전 문서의 test 수치나 기사·기업 전체 행 정확도와 섞지 않습니다.

| 지표 | 기존 GNN | 문맥 입력 GNN | 뉴스 제거 GNN |
|---|---:|---:|---:|
| 직접 기업 정확도 | **39.61%** | 39.45% | 39.59% |
| 간접 기업 정확도 | **37.53%** | 37.43% | 37.29% |
| 전체 기업 정확도 | **37.67%** | 37.57% | 37.41% |
| 전체 강도 MAE(낮을수록 좋음) | **0.204599** | 0.205567 | 0.205222 |

직접 기업의 시장·기간별 정확도:

| 조건 | 기존 GNN | 문맥 입력 GNN | 뉴스 제거 GNN |
|---|---:|---:|---:|
| KOSPI 1일 | 37.78% | 38.37% | 37.81% |
| KOSPI 3일 | 38.64% | 39.00% | 38.70% |
| NASDAQ 1일 | 41.56% | 40.69% | 41.41% |
| NASDAQ 3일 | 40.48% | 39.74% | 40.45% |

KOSPI 직접 기업에서는 +0.59/+0.36%p지만 NASDAQ 직접 기업에서는 −0.87/−0.74%p입니다.
두 시장·기간 평균은 기존 대비 **−0.165%p**, 뉴스 제거 대비 **−0.143%p**였습니다.
간접 평균 정확도는 기존 대비 −0.102%p, 전체 강도 MAE는 +0.000968입니다.
사전에 기록한 기술적 채택 조건을 통과하지 못했습니다.
48개 HAC 비교(24개 × lag 2개)에서 Holm 보정 후 유의한 차이는 없었습니다.
따라서 통계적으로 악화가 확정됐다고 주장하지도 않습니다.

**해석:** 기업명을 포함하도록 입력을 고친 것만으로는 현재 구조·손실에서 추가 예측력을
확인하지 못했습니다. 뉴스가 무의미하다는 증거는 아닙니다. 기사별 공통 임베딩, 짧은
문맥 창, 직접 기업의 약 6% 손실 계수 비중, 일별 가격 라벨의 잡음은 여전히 남습니다.
다음 독립 실험은 **기존 입력에서 직접·간접 손실 비중만 50:50으로 변경**하는 것입니다.
손실 변경 시에는 뉴스 제거 대조군도 같은 손실로 다시 학습해야 합니다.
이번 실행에서는 손실 변경이나 추가 탐색을 하지 않았습니다.
