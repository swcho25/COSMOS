## 현재 상태 요약

전체 원천 데이터 약 1,300만 건을 모두 모델에 넣은 것이 아니다. 기업명이 연결된 후보를 빠른 분류기와 근거 검사로 줄였으며, 주요 단계별 수량은 다음과 같다.

| 근거 검사 후 그래프 뉴스 | 219,790기사 / 246,264쌍 | 원문 근거와 기업 귀속을 통과한 분석 자료 |
| 서비스 canonical 뉴스 | 219,662기사 / 246,117쌍 | 중복 리비전을 통합한 운영 조회 자료 |

| 관계 근거 | 541개 | 뉴스 177개 + 공시 364개 |

기업별 감성은 분석 174,680쌍과 보류·미판정 71,584쌍으로 구성된다. 운영 canonical 기준 감성 분포는 긍정 95,479, 부정 23,621, 중립 55,437, NULL 71,580이다.

### GNN

- 기존 U3 GNN은 기업 코드와 고정 관계 그래프를 받아 관계 이웃의 상대 영향 순위를 반환한다. 뉴스 본문을 조건으로 호재·악재를 판단하는 모델이 아니다.
- 2026-09-19 grounded 후보는 뉴스 문맥과 새 그래프를 반영해 9회 학습했지만 성능 개선이 확인되지 않았다.
- 새 후보의 4개 시장·기간 거래일 정확도 평균은 39.5138%, 시장별 기준선은 40.8213%였다.
- 동일 4,813쌍 비교는 기존 stage3 39.6143%, 새 후보 37.4494%였다.
- 따라서 기존 모델을 유지했으며 새 후보를 운영 모델로 교체하지 않았다.
