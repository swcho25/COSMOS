## 실행과 재개

저장소 루트에서 다음 명령으로 숨김 백그라운드 프로세스를 시작한다.
동일 출력에 저장된 프로토콜이 있으면 자동으로 `--resume`을 붙인다.

```powershell
& .\AI\graph\start_kg_b_provisional.ps1
```

이 명령은 예약 작업을 만들지 않는다. PC를 다시 켠 뒤 직접 실행하거나 Codex에 재개를 요청한다.
절전·프로세스 종료·PC 종료 중에는 로컬 GPU 처리가 멈춘다.
2026-09-18 확인한 전원 설정은 AC연결 시 자동절전 없음, 배터리에서는 유휴30분 후 절전,
덮개를 닫으면 AC/DC 모두 절전이다. 충전기 연결·덮개를 연 상태에서 화면보호기/잠금/화면 꺼짐은 계속 처리한다.
전원 설정 자체는 변경하지 않았다.

처리 중인 묶음을 저장하고 정상 정지하려면 출력 폴더에 `STOP` 파일을 만든다.

```powershell
New-Item -ItemType File -Path .\AI\graph\artifacts\kg_b_provisional_full_20260918_v1\STOP -Force
```

그 요청으로 멈춘 실행은 다음 명령으로 명시적으로 이어간다.

```powershell
& .\AI\graph\start_kg_b_provisional.ps1 -ResumeAfterStop
```

단순 PC 종료/절전은 STOP 파일을 만들지 않으므로 일반 재개 명령을 사용한다.

처음 실행한 모델·입력·코드·설정을 고정하고, 변경된 구성으로 기존 결과를 이어 붙이지 않는다.
32쌍의 예측 결과와 입력 cursor를 SQLite transaction에 함께 저장한다.
중간에 끊기면 마지막 커밋은 유지되고 커밋되지 않은 묶음만 다시 처리한다.
`chunk-size=32`는 저장 단위이며, 기사 32개를 GPU에 동시에 넣는다는 뜻은 아니다.
실행 중 입력·모델·고정 Python 코드를 수정하거나 `state.sqlite3` 및 그 `-wal`/`-shm` 파일을 삭제하지 않는다.

실행 기록: `artifacts/kg_b_provisional_launch_20260918_v1/launch_*.json`과 stdout/stderr 로그.
현재 진행은 출력 폴더의 `status.json`에서 확인한다. 오래된 상태 파일만 보고 실행 중이라고 판단하지 않는다.
