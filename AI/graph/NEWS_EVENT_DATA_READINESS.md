# 금융 사건 확장 학습의 시각·기업 이력·평가 계약

2026-09-15. 로컬 저장소와 보존된 원천 추출 파일을 읽어 확인했다. 외부 발행사나
거래소의 계약을 새로 검증한 문서가 아니다. 원본 기사·가격·라벨·모델은 수정하지 않았다.

## 원천 시각에서 확인한 범위

`README_NEWS_QUALITY_DATASET.md`의 원천별 시각 집계와
`news_quality_source_20260915`의 메타데이터는 보존되어 있다. 저장소 전체에서
`published_timezone`, `published_at_iso`, `date_normalization_method`와 원천 이름을 검색했지만,
실제 원천별 발행·수정 시각의 정의 및 시간대 변환을 구현한 수집 코드는 발견하지 못했다.
검색된 구현은 이번 추출/감사 스크립트였고, 기존 NER 인계에는 원천별 분포와 본문 오염만 기록돼 있다.
따라서 `mysql_domestic`의 UTC와 일부 국내 S3의 +09:00가 형식상 명시됐다는 사실을
"최초 발행시각과 당시 원문이 인증됐다"는 뜻으로 바꾸지 않는다.

현재 실험에서는 기존 `news_impact_data.availability(published_date, region)`를 그대로 쓴다.
국내 날짜는 서울 기준 다음 날 0시, 해외 날짜는 UTC−12 기준 다음 날 0시다.
기사마다 보관된 `available_at`과 재계산값이 같은지 검사한다. 복원한 시각은 감사 필드로만 둔다.
원문에 날짜만 있는데 정규화 필드에 자정이 붙었다고 정확한 발행시각으로 사용하지 않는다.
수집시각도 최초 발행시각을 대신하지 않는다.

## 과거 기업 식별에서 확인한 범위

`AI/ner/data/company_industry.csv`, `companies.csv`, `aliases.csv`, `data/db/company.csv`에는
현재 종목·기업·별칭 정보가 있다. IPO/상장일, 별칭 유효기간, 법인 분할·합병의 유효기간을
정의하는 역사 테이블은 찾지 못했다. `prices_manifest.json`의 상장 관련 설명은 수집 기록이며
독립적인 법인·상장 이력 검증이 아니다.

예를 들어 현재 사전은 `삼성바이오에피스`와 `Samsung Bioepis`를 `0126Z0`에 연결한다.
해당 이름을 과거 기사에서 발견했다고 당시 상장된 동일 법인의 주가가 존재했다는 결론은 안 된다.
종목 코드가 이어지더라도 법인 정체성, 상장 시장, 모회사·자회사 관계가 이어지는지는 별도 문제다.

로컬 자료만으로 강제할 수 있는 보수적 조건은 다음과 같다.

> 새로운 학습 사건의 대상 종목은 기사 `available_at`보다 이른 시각에,
> 유한하고 양수인 수정종가 관측이 최소 한 번 있어야 한다.

이는 **로컬 가격 관측 이력 조건**이다. 최초 가격 날짜를 IPO 날짜라고 부르지 않는다.
이 조건을 통과해도 당시 법인·별칭의 정체성을 인증하지 못한다. 입력이 부족한 기업을 미래에
생긴 종가에 연결하는 일을 막는 용도로만 쓴다. 미래 가격 결과나 정답 방향은 선택에 사용하지 않는다.
기존 val/test의 후보나 정답은 이 조건으로 지우거나 바꾸지 않는다.

`artifacts/current_event_readiness_20260915/audit_readiness.py`로 실제 28,026개 후보를 검사했다.
이 집계는 사건 주체/시점의 추가 정제 **이전** 모집단이다.

| 대상 | 전체 기사×기업 | 과거 가격 관측 없음 | 해당 기사 |
|---|---:|---:|---:|
| 문자열로 재확인한 기업 | 57,401 | 2,032 | 1,931 |
| 기존 자동 사건 기업 | 39,402 | 1,388 | 1,371 |

자동 사건 기업 전부가 이 조건을 충족하지 못하는 기사는 688건이다.
미관측 사건 쌍은 HD현대중공업 399, LG에너지솔루션 167, SpaceX 144, Airbnb 124건 등이다.
이는 기업별 오인식률이나 비상장 비율이 아니다. 당시 가격이 로컬 데이터에 없다는 결과다.
기존 기사 멘션에도 train 1,067 / val 94 / test 149개의 미관측 연결이 있으며,
라벨 생성 후 살아남은 학습 쌍 수와는 다르다.

전체 종목 경계는 `price_observation_boundaries.json`, 대상 후보는
`candidate_no_prior_price.jsonl`, 집계와 입력 해시는 `readiness_audit.json`에 보관했다.

## 확장 학습 라벨의 안전한 연결 지점

별도 `news_impact_graph.py`는 없다. 라벨·그래프 구현은 `news_impact_data.py`에 함께 있다.

1. `companies()`와 `prices()`로 기존 202종목 순서와 수정종가를 읽는다.
   `news_impact_v2/index_KOSPI.csv`, `index_NASDAQ.csv`를 그대로 읽어 `Labels`에 전달한다.
   누락 지수일을 채우거나 달력을 압축하지 않는다.
2. 추가할 기사만 `Labels.label(ticker, available_at, 'train')`에 넣는다.
   원래 시장 달력의 가용 시각 이후 첫 종가가 anchor이고, +1/+3거래일 수정종가
   로그수익률에서 실제 시장 지수 로그수익률을 뺀다. 즉시 뉴스 반응이나 인과 정답이 아니다.
   +3 종료일이 2022년 말 경계를 넘거나 창 내부 가격·지수가 없으면 제외한다.
3. 원래 `articles.jsonl` 순서와 `pairs.parquet` 행을 보존하고 신규 학습 기사·쌍을 뒤에 추가한다.
   기존 기사 재정제의 손실 마스크와 새 사건의 학습 손실 마스크를 별도 저장한다.
   재정제 때문에 예측하지 못한 기존 val 70쌍도 원래 4,813쌍 분모에서 사라지면 안 된다.
4. 원래 `label_config.npz`의 방향 임계와 강도 척도를 고정한다.
   1/3일 중립 임계는 각각 0.0049576047 / 0.0089788064, 강도 척도는
   0.0354772992 / 0.0615163445다. 확장 학습으로 이를 재추정하면 기존 val의 정답
   클래스 자체가 달라진다. `TrainingData` 기본 생성자는 임계를 다시 추정하므로 그대로 쓰면 안 된다.
5. 기준 모델과 확장 모델은 같은 입력 정제, 종목 순서, 그래프와 평가 쌍을 사용한다.
   뉴스 제거 모델도 동일한 확장 학습 표본으로 별도 학습한다. 결과는 기사별 예측을
   거래일 단위로 묶고 시장×1/3일을 동일하게 평균하여 원래 목표와 비교한다.
   이미 반복해서 본 2023 val의 개선을 새 독립 기간에서 확인된 개선이라고 부르지 않는다.

`build_dataset()`을 원래+추가 기사 전체에 다시 실행하는 것은 이 계약과 다르다.
`read_news()`의 날짜순 전체 중복 제거가 val/test 기사를 선점할 수 있고, `expand()`가 새 그래프로
평가 후보를 다시 만들며, 기사 인덱스도 바뀐다. 별도 확장 wrapper가 위 조건을 지켜야 한다.

## 정제된 과거 그래프의 연결 지점

기존 `make_graph(cutoff, docs, meta, price, ownership_history)`는 `docs` 외에도
`data/rel_hits.jsonl`을 직접 읽는다. 정제한 기사만 넘겨도 예전 관계 근거가 정제되지는 않는다.
현재 `edges_correlation.csv`, 전체 기간 공동언급, 현재 업종·지분을 과거에 넣지 않는다.

확장 대조 실험은 다음의 좁은 그래프를 별도로 만든다.

- 공동언급은 정제된 학습 기사에서 당시 확인한 기업만 사용하며, 기사 가용 시각이 연초
  스냅샷 시각보다 앞서는 근거만 채택한다. 자료 제공사·배경 기업을 무조건 사건 기업으로 보지 않는다.
- 상관은 해당 연도 이전 한 해의 같은 시장 수정종가 수익률만 사용하고, 기존 최소 60관측을 유지한다.
- 재검수하지 않은 `rel_hits` 관계와 현재 sector/ownership는 이 실험에서 제외했다고 기록한다.
  이 실험은 전체 원래 관계 유형의 효과를 검증하지 않는다.
- `graph_arrays`, `node_features`는 정해진 202종목 순서로 재사용할 수 있다. 역사적 업종 정보가
  없으면 마스크를 유지한다. 각 엣지의 원문 ID·기사 날짜·가용 시각과 그래프 시점을 감사한다.
- 기준/확장/뉴스 제거가 같은 그래프를 사용하는 경우, 학습 기사 확대가 노드 입력·손실에 미치는
  효과를 비교한다. 공동언급 그래프 자체의 확대 효과를 분리 입증한 결과는 아니다.

남은 외부 자료는 발행/수정 시각 계약, 과거 별칭·법인/상장 이력, 독립적인 사건 주체·시점 검수,
새 후속 평가 기간이다. 로컬 관측 조건과 자동 텍스트 정제를 이 자료들의 완전한 대체로 소개하지 않는다.

## 이번 확장 산출물의 실행 확인

`experiment_current_events.py --stage prepare`의 **첫 후보 버전**
`artifacts/news_current_events_20260915`를 당시 코드로 `verify_current_events.py --data-only` 검사했다.
이후 괄호 안 인수 대상 기업을 주체로 잡는 문제와 `지난해` 배경을 놓치는 문제를 발견해
이 버전은 학습하지 않고 보존했다. 실행 검증 통과가 사건 의미의 정확성을 보증하지 않는 사례다.
후속 v2는 별도 폴더로 다시 준비·검증했다. 다음 숫자는 첫 후보 버전의 기록이다.
새 사건 규칙·로컬 관측 이력·라벨 창 조건을 통과해 추가된 학습 기사는 4,173건,
직접 기업 쌍은 4,390개다. 기존 학습에서 같은 사건 조건을 통과한 기사는 507건/529쌍이다.
이는 자동 선택 학습 표본이며 사람 검수 정답이 아니다.

- 기존 기사 29,827개 식별·날짜·가용 시각과 기존 845,742쌍 전체 행을 보존했다.
  기존 val 입력 마스크·특징 매핑·언급 배열과 방향 임계를 대조했다.
- 신규 8,780개 연속값 정답을 원래 수정주가·지수의 개별 로그수익률로 독립 계산했다.
  최대 차이는 3.12×10⁻¹⁵다. 신규와 val/test의 ID·본문 해시 겹침은 없었다.
- 2017~2023 연초 그래프의 모든 엣지를 검사했다. 2023 그래프는 공동언급 54개,
  과거 가격 상관 756개다. 2017·2018에는 공동언급 엣지가 없다.
  이 그래프는 가격 상관 비중이 높으며 모든 관계 유형을 복원한 그래프가 아니다.
- 원래 val 직접 4,813쌍 중 기존 본문 정제 규칙을 통과한 4,743쌍이 그대로 유지됐다.
  원래 분모에 남는 70개의 미응답을 포함해 목표 달성 여부를 판단한다.

이 항목은 학습 전 데이터 검증 결과다. 모델 성능은 별도 학습 완료 리포트에서 확인한다.

### 두 번째 후보 버전의 학습 전 검증

`artifacts/news_current_events_20260915_v2`에서는 강화된 사건 규칙으로 기존 학습
409기사/420쌍을 유지하고 새 3,493기사/3,621쌍을 추가했다.
같은 검증기를 다시 실행해 원본 보존, 가용 시각, 고정 임계·PCA, 원래 평가 모집단,
학습/평가 중복 검사를 통과했다. 신규 정답 7,242개를 독립 재계산했고
최대 차이는 3.12×10⁻¹⁵다. 2023 그래프는 공동언급 32개와 과거 가격 상관 756개다.
`news_current_events_20260915_v2/data_verification.json`이 해당 실행의 결과다.

### 두 번째 버전 재학습 후 검증

9개 체크포인트를 실제 학습한 뒤 같은 검증기의 전체 모드를 실행했다.
CPU 9개 체크포인트에서 6개 val 기사 예측을 재생했고 최대 차이는 1.19×10⁻⁷이었다.
새 학습 대상 6쌍의 동결 인코더를 CPU에서 다시 실행한 차이는 최대 7.75×10⁻⁷이었다.
평가지표 24개와 거래일 HAC 비교 40개, 시차별 Holm 20개 비교 보정을 독립 대조했다.
최대 지표/통계 오차는 각각 5.56×10⁻¹⁷ / 4.45×10⁻¹⁶ 이하였다.

원래 4,813쌍과 미응답 분모를 유지한 시장×기간 평균 정확도는 기존 기사 정제 기준 35.67%,
추가 기사 학습 38.18%, 같은 추가 기사에서 뉴스 입력 제거 37.44%, 원래 모델 39.61%다.
추가 학습은 이번 정제 기준 모델보다 점추정이 높았으나 원래 모델을 넘지 못했다.
뉴스 입력의 추가 이득은 각 시장×기간의 다중 비교 보정 후 확인되지 않았다.
이 실행에서도 65% 목표는 미달이며, 원래 모델을 대체하지 않는다.
전체 재생 검증 결과는 `news_current_events_20260915_v2/reload_verification.json`에 있다.
