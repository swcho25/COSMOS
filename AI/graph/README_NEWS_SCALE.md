## 사전에 정한 질문

동일한 기사 모집단에서 학습에 쓰는 기사 수를 약 2만·5만·10만으로 늘리면,
현재 뉴스 입력 GATv2의 방향 정확도가 높아지는가? 뉴스 내용을 제거한 대조군보다도
높아지는가? 확보 가능한 기사 수가 목표보다 적으면 실제 최대치를 별도 이름으로 보고한다.

13,259,404는 HDFS 준비본의 원천 행 수다. 고유 기사 수, 학습 기간의 기업 연결 기사 수,
현재 사건 기사 수, 가격 정답을 만들 수 있는 기사 수와 같지 않다.

사용자 질문 “뉴스19만건만 쓰는가?”에 대한 구분:189,101건은 이번 고정 추출 정책의
원천 후보이며, 로컬 적격 기사는108,538건, 최대 모델 학습 기사는100,000건이다.
12개 연도·지역 구간 모두 해당 정책의 후보를 전량 추출했으므로 이번에는 구간별
50,000건 상한을 더 높여도 후보가 늘지 않는다. 더 확대하려면 학습 기간이나 기업 연결·
금융 후보 정책을 별도 설계해야 하며, 이미 평가에 사용한2023년 이후를 그대로 학습에
추가해 같은 검증 성능과 비교해서는 안 된다.

## 네 작업의 범위

1. 국내외·2017–2022년·자동 채택/제외 24개 층에서 각 10건, 총 240건을 별도 가격·예측 데이터 없이 검토했다.
   검토 모집단은 종전54,683후보이며, 새189,101후보나100,000학습 기사의 정밀도를 인증한 표본이 아니다.
   자동 채택 여부와 제외 이유를 숨긴 별도 본문 패킷을 읽고 개별 판정과 정확한 인용을 보관한다.
   **AI 보조 검토이며 사람 검수 정답이 아니다. 사람 검수 완료는 0건이다.**
   이 표본에 맞춰 기사 필터를 튜닝하지 않는다.
   `SCALE_SEMANTIC_REVIEW.md`: 채택 표본 120건은 지지77/비지지27/보류16,
   제외 표본120건은 지지45/비지지63/보류12다. 균등 진단 표본이므로 전체 자료의
   precision/recall이 아니다. 원문 안의 후대 시세 위젯·삽입 피드는 오염으로 기록했다.
2. 같은 품질 기준을 적용한 모집단에서 중첩 표본으로 데이터 규모를 비교한다.
3. 시각의 원천 근거와 기존/가상 정렬의 차이를 진단한다. 확인되지 않은 시각으로 기존 정답을
   덮어쓰지 않는다. 상세 결과는 `SCALE_TIME_EVALUATION_AUDIT.md`에 있다.
4. 미사용 후속 기간의 자료 유무와 정답 성숙도를 확인한다. 현재 가격은 KOSPI 2026-09-11,
   NASDAQ 2026-09-10까지여서 새 양시장 1/3일 평가를 실제 수행할 수 없다.
   이미 사용한 2024–2026-09-11을 다시 미사용 기간이라고 부르지 않는다.

## 데이터 규모 실험의 고정 조건

- 원천은 기존 HDFS 준비본과 dict-v1.3 기업 연결이다. 2017–2022년만 추출한다.
- 기존 제목/본문 앞부분 금융 키워드와 `financial-quality-v1:` 해시 순서를 유지한다.
  새 출력 경로만 사용하고 원천을 수정하지 않는다. 최초 cap은 연도·지역별 25,000건이다.
  부족할 때는 상한에 걸린 층만 확대하며, 이전에 전부 추출한 층은 해시 검증 후 재사용한다.
- 모든 학습 규모에 같은 본문 정제·문자열 기업 확인·같은 문장 금융 표현 조건을 적용한다.
  극히 좁은 `current_event_gate`는 적용하지 않는다. 따라서 자동 후보는 실제 사건 주체를
  인증한 정답이 아니며, 검토에서 드러난 잔여 오류를 한계로 남긴다.
- 모든 텍스트 입력 기업은 기사 가용 시각 이전에 양수·유한한 수정종가가 있어야 한다.
  정답 없는 입력 기업도 같은 조건을 적용한다. 이것은 과거 법인 정체성 인증이 아니다.
  기업 제거 후에도 남은 입력 기업 중 하나 이상이 같은 문장 금융 표현 조건을 충족해야 한다.
  기사 단위 조건이므로 모든 정답 대상 기업의 사건 주체 여부를 인증하지는 않는다.
- 원래 검증·시험 기사와 ID, 원문/정제 본문 해시, canonical URL 중복을 차단한다.
- 먼저 공통 적격 모집단을 확정하고, 국내외·연도별 비중을 유지하는 해시 순서로 중첩 표본을
  만든다. 2만 표본은 5만 표본의 부분집합이며, 5만은 최대 표본의 부분집합이다.
- 새 실험의 2만 기사는 공통 모집단에서 다시 추출한다. 종전 20,458기사와 동일한 표본이 아니다.
  규모 효과는 이번 실험의 작은/큰 표본 사이에서 판정한다.
- 인코더·기존 학습 PCA64·연도별 과거 그래프·방향 임계·강도 척도를 모두 공통으로 고정한다.
  **지도학습 예제 수의 효과**를 비교하며, 인코더 사전학습이나 그래프의 총정보량까지 제한한
  순수한 전체 데이터 예산 실험이라고 부르지 않는다.
- GATv2 2층, hidden64, dropout0.15, batch24, AdamW lr0.0008/weight decay0.001,
  최대30epoch/patience6, 직접 기업 방향 CE+강도 Smooth L1, 최소 복합 검증 손실로 선택한다.
- 각 규모에서 뉴스 포함/본문·감성 0 대조군을 각각 3시드 학습한다. 언급·기업ID·그래프는
  대조군에도 남는다. 규모에 따라 업데이트 횟수와 조기종료 시점이 달라질 수 있다.

## 평가와 검증

2023년 원래 직접 검증 4,813쌍을 그대로 채점한다. 입력 정제로 빠진 70쌍도 오답이며,
예측 가능한 4,743쌍만의 점수는 보조다. 시장×1/3일의 각 셀에서 거래일별 정확도를 먼저
평균한 뒤 네 셀을 동일 가중한다. 검증 기사나 중립 경계를 바꿔 점수를 높이지 않는다.

새 자료는 compact 인덱스를 사용한다. `original_validation_indices.npy`로 원래 모델의
예측에 정확히 대응하며 원래 정답·뉴스·기업 identity가 보존됐는지 독립 검증한다.

모든 규모 쌍의 뉴스 모델 비교, 각 규모의 뉴스/뉴스 제거 비교, 각 뉴스 모델과 동결된
원래 GNN·종목 빈도·시장 다수 기준선을 학습 전에 고정한다. HAC lag5/20과 각 시차의 전체
대조×4셀 Holm 보정을 적용한다. 개별 95% 구간은 다중 비교 보정 전 구간이다.

이미 반복해서 사용한 검증이므로 결과는 탐색적이다. 65%를 보장하지 않으며, 높은 확신의
일부 기사만 골라 얻은 정확도를 전체 65% 달성으로 바꾸어 표현하지 않는다.

## 원격 후보 추출 결과 — 아직 모델 성능 결과 아님

원천13,259,404행 중 학습 기간2017–2022는8,794,170행,
본문 사용·대표 기사 조건은6,591,884행이다. 기업 연결 단계 집계는846,236행이며,
금융 키워드 후보189,101건(국내154,628/해외34,473)을12개 구간에서 전량 추출했다.
이 후보는 아직 로컬 본문 정제·중복 배제·주가 정답 검사를 거친 학습 기사 수가 아니다.

첫 cap25k와 두번째 cap50k 실행은 마지막 해외2022에서 Java heap OOM으로 실패했다.
두번째는 Parquet 읽기 batch128·partition64MiB·동기 캐시 해제를 적용했으나,
본문 출력 중 압축 해제 메모리 부족이 남았다. 완료11구간을 보존·검증해 재사용하고
