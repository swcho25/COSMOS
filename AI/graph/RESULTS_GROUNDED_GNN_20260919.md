# 뉴스·공시 그래프와 GNN 재학습 결과

2026-09-19 요청한 1~5단계의 로컬 산출물과 검증을 완료했다. **새 GNN의 성능 개선은 확인되지 않았다.** 기존 서비스 모델은 교체하지 않았으며 6단계 백엔드 전달·연동 검증은 시작하지 않았다.

## 단계별 산출물

| 단계 | 완료한 내용 |
|---|---|
| 1 뉴스 관계 추출·검수 | 원문 근거를 대조한 뉴스 관계 근거 168개 유지, 15개 보류 |
| 2 공시 관계 추출 | DART 원문 근거 364개와 기업 ID·발행 시점·출처 연결 |
| 3 통합·점수 계산 | 관계 112개, 근거 532개, 원문 422문서; 7D·30D·90D 구성 점수 검산 |
| 4 GraphRAG 근거 연결 | 뉴스·공시 검색 및 관계 설명, 전체 112관계 인용 검증 |
| 5 GNN 재학습·평가 | 후보·뉴스 제거·신규 그래프 제거 각각 3시드, 총 9회 학습 및 독립 재검산 |

관계는 공급 17개, 투자·지분 54개, 협력 34개, 경쟁 7개다. 관계 개수와 근거 문서 수는 서로 다르다. 공시 전체 이력을 처리했다거나 사람이 검증한 정답 데이터가 완성됐다는 의미는 아니다.

현재 스냅샷에는 동일 기업쌍·관계 종류·기간에 뉴스와 공시 점수가 모두 있는 행이 없다. 따라서 계산 기능은 구현됐지만 현재 개인화 슬라이더 효과까지 충분히 확보한 것은 아니다. 한 출처가 없으면 NULL로 보존한다.

실제 생성형 설명에서 원문에 없는 공동 사업 표현이 NLI 검사를 통과하는 문제가 있었다. 권장 설명기는 원문 인용과 제한된 관계 설명을 반환하는 `safe_integrated_relation_explanations.py`다. 생성형 설명의 정확성이 입증됐다는 주장은 하지 않는다.

## 학습과 평가 범위

- 최종 입력: `artifacts/grounded_gnn_20260919_v1/dataset_v3`.
- 학습 99,407기사·111,376감독 쌍, 검증 36,074기사·40,627쌍, 테스트 33,210기사·36,518쌍.
- 테스트에서 격리한 11쌍도 분모에 포함하고 미응답을 오답으로 처리했다.
- 9회 학습, 합계 72에포크. 실제 학습 시간 03:50:26~05:00:56 KST, 약 70분 31초. 전처리·그래프·독립 검증 시간은 별도다.
- 시간순 분할과 과거 그래프를 사용했다. 검증·테스트 시기는 과거 실험에서 이미 본 자료이므로 새로운 비공개 최종 평가가 아니다.
- 이번 가격 라벨 평가는 직접 관련 기업에 대한 평가다. 간접 영향의 예측력을 검증한 결과가 아니다.

## 테스트 결과

아래는 각 시장·예측 기간의 **기사–기업 쌍 단위 방향 정확도**다.

| 모델 | KOSPI 1일 | KOSPI 3일 | NASDAQ 1일 | NASDAQ 3일 |
|---|---:|---:|---:|---:|
| 새 GNN | 42.42% | 40.02% | 41.21% | 39.25% |
| 뉴스 제거 | 42.82% | 40.11% | 41.52% | 38.60% |
| 신규 그래프 제거 | 41.89% | 39.98% | 41.18% | 39.02% |
| 시장별 기준선 | 41.64% | 42.73% | 43.65% | 42.37% |

거래일마다 정확도를 계산한 뒤 시장×기간 4개 셀을 동일 비중으로 평균하면 새 GNN 39.5138%, 뉴스 제거 39.7761%, 신규 그래프 제거 39.7542%, 시장별 기준선 40.8213%다. 표의 쌍 단위 정확도와는 가중 방식이 다르다.

후보의 우위는 HAC 검정과 Holm 보정에서 확인되지 않았다. KOSPI 3일에서는 시장별 기준선보다 거래일 평균 정확도가 4.1188%p 낮았고 보정 후에도 유의했다(lag 5 p=0.03743, lag 20 p=0.01782). 목표 65%에 도달하지 못했다.

## 실제 기존 모델과 동일 표본 비교

기존 모델의 동결 예측과 새 후보를 동일 2023년 직접 관련 4,813쌍으로 비교했다. 뉴스·기업·정답·기준일 등 13개 식별 열과 라벨 설정을 확인했다. 새 후보의 미응답 70쌍도 분모에 포함했다.

| 모델 | 시장×기간 4셀의 거래일 정확도 동일 비중 평균 |
|---|---:|
| 기존 배포 후보 GNN(stage3) | 39.6143% |
| 새 GNN | 37.4494% |

새 후보는 이 보조 비교에서도 2.1649%p 낮았다. 이미 본 평가 기간이며 전처리와 학습 모집단도 달라, 새 비공개 검증이나 특정 변경의 인과 효과로 해석하지 않는다. 이 비교의 유의성 검정은 하지 않았다. `no_new_graph` 대조군은 실제 기존 모델과 다르다.

## 독립 검증과 보고서 수정

72개 지표 행, 120개 통계 대비, 예측 앙상블·분모·SHA 및 9개 체크포인트 재로딩 검증이 통과했다. 원래 학습 보고서에서 상수 기준선의 순위 상관 12개가 NaN으로 기록된 문제를 발견했다. float32 표준편차의 상수 판별 문제였다. 기존 정책대로 상수 예측의 순위 상관을 0으로 계산한 **별도 수정 CSV**를 만들었다. 정확도·F1·MAE·통계 검정·모델·예측·원래 보고서는 변경하지 않았다.

자동 후속 검증의 최초 실행은 Windows PowerShell의 `Get-FileHash` 사용 실패로 중단됐었다. .NET SHA 계산으로 수정한 래퍼를 실제 재실행했고, 새 상태 파일은 `verified_with_rank_report_correction`이다. 최초 실패 기록은 보존했다.
