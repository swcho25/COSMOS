# 직접·간접 손실 균형 GNN 대조 실험

**2026-09-15 완료: 9개 모델 학습 및 검증 통과. 전체 정확도는 소폭 상승했지만,
직접 기업 정확도 및 뉴스 제거 대비 추가 이득은 개선하지 못해 기존 모델을 유지한다.**

## 목적과 고정 조건

기존 기사별 후보 평균 손실에서 직접 기업의 평균 계수 비중은 train 기준 약 6.12%였다.
이는 실제 gradient 기여율이 아니라 손실을 합산할 때의 계수 비중이다.
간접 후보 수에 따라 직접 기업 학습이 희석되는 문제를 검토하기 위해,
기사마다 직접 기업 평균 손실과 간접 기업 평균 손실에 각각 50%를 배정한다.
라벨이 있는 그룹이 하나뿐이면 그 그룹에 100%를 배정하며 기사별 비중은 동일하다.
방향 CE와 강도 Huber 및 1일/3일의 평균 방식은 유지한다.

학습 전에 세 조건을 고정했으며 각 시드 0/1/2, 총 9개 모델을 학습한다.

| 조건 | 뉴스 특징 | 손실 |
|---|---|---|
| balanced_original | 기존 임베딩·감성 | 직접·간접 그룹 50:50 |
| balanced_context | 이전 기업 문맥 실험의 임베딩·감성 | 동일 |
| balanced_no_content | 임베딩·감성을 모두 0 | 동일 |

후보 기업·언급 메타데이터·회사 ID·정적 특징·과거 그래프·시간 분할·라벨은 유지한다.
뉴스 제거는 회사명 언급 여부까지 제거한다는 의미가 아니다.
기업 문맥 입력은 여전히 기사당 공통 임베딩이며 기업별 개별 임베딩은 아니다.
문맥 인코더는 다시 실행하지 않고 이전에 고정한 특징과 train PCA를 재사용한다.

GATv2 2층, hidden 64, dropout 0.15, PCA 64, AdamW lr 0.0008, weight decay 0.001,
batch 24, 최대 30에폭, patience 6, gradient clip 2를 유지한다.
체크포인트는 **새 그룹 균형 validation 손실**로 선택한다.
따라서 기존 학습 로그의 validation 손실과 숫자 자체를 비교하면 안 된다.

## 평가 기준

새 모델은 validation 90,157쌍만 예측하고 원본 행 번호 `pair_indices`를 함께 저장한다.
새 test forward/예측/지표 계산은 하지 않는다. 이미 개발에 사용한 validation을 재사용하므로
이번 결과는 독립된 미래 일반화 검증이 아니다.

두 뉴스 입력 후보를 기존 GNN, 기존 뉴스 제거 GNN, 새 균형 뉴스 제거 GNN,
전체 다수 클래스, 시장별 사전 분포, 종목별 사전 분포, LightGBM과 비교한다.
이전 문맥 GNN의 지표도 참고용으로 함께 기록한다.

주 지표는 거래일별 정확도를 구한 뒤 거래일에 같은 비중을 둔 정확도다.
시장 2개 × 기간 2개의 네 셀을 같은 비중으로 평균해 직접·간접·전체를 각각 보고한다.
행 단위 정확도, 클래스별 재현율·예측 비율, balanced accuracy, 강도 MAE도 저장한다.
클래스 순서는 부정/중립/긍정이며 일반 accuracy와 balanced accuracy는 서로 다른 지표다.

두 후보 × 7개 비교군 × 3개 범위 × 2개 시장 × 2개 기간 = 168개 비교에 대해
HAC lag 5와 lag 20을 각각 계산한다. lag별 168개 전체를 하나의 Holm 보정 묶음으로 처리한다.
총 336개 비교이며 신뢰구간은 보정 전 구간이다. 3시드를 독립된 거래일 표본으로 세지 않는다.
통계는 방향 정확도에 적용하며 강도 MAE에 통계적 우위를 주장하지 않는다.

사전 기술적 채택 조건은 직접 기업 네 셀 평균 정확도가 7개 비교군보다 모두 높고,
간접 정확도와 전체 강도 MAE가 기존 모델보다 나쁘지 않은 것이다.
조건 충족 자체가 통계적 우위나 서비스 채택을 의미하지 않으며 자동 교체는 없다.

`TrainingData`의 PCA 쓰기는 별도 복사본에만 수행한다.

`protocol.json`을 학습 전에 저장한다. 각 조건 폴더에는 3개 체크포인트,
시드별 validation 예측과 앙상블, 학습 이력, 연구 전용 `MODEL_POLICY.json`이 있다.
루트에는 선택 에폭, 세부·평균 지표, 통계 비교, 완료 기록, CPU 재로딩 검증을 저장한다.
해당 폴더는 배포 번들이 아니며 기본 API에 경로만 바꿔 연결하면 안 된다.

기존 문맥 실험의 세 모델 지표를 다시 계산해 행 순서·라벨·평균 방식이 같은지 확인한다.
검증 스크립트는 국내·해외 처음/중간/마지막 validation 기사 6건에 대해 9개 체크포인트를
CPU에서 다시 실행한다. 모든 validation 행의 시드 평균도 검사하고,
pandas 거래일 집계와 별도 수식으로 336개 HAC·Holm 계산을 교차 검증한다.
이번 CPU 검증은 저장된 인코더 특징부터 시작한다. 원문부터 문맥 인코더 재실행은
이전 `verify_news_context.py`에서 수행했다.

총 101에폭을 수행했다. 아래 선택 에폭은 0부터 센 값이다.

아래 정확도는 validation의 시장×기간 네 셀 평균이며 각 셀은 거래일에 동일 가중치를 둔다.

기존 입력 + 균형 손실은 전체 정확도 **+0.423%p**, 간접 정확도 **+0.452%p**지만,
목표였던 직접 정확도는 **−0.137%p**다. 같은 손실의 뉴스 제거보다 직접 정확도가
**0.704%p 낮다**. 문맥 + 균형 손실도 기존보다 직접 정확도가 0.051%p 낮고,
같은 손실의 뉴스 제거보다 0.617%p 낮으며 전체 강도 MAE는 0.002435 커졌다.
두 후보 모두 사전 기술적 채택 조건을 통과하지 못했다.

HAC·Holm 336개 비교에서 기존 모델 대비 유의한 정확도 개선은 없었다.
일부 NASDAQ 구간에서는 다수 클래스·시장별 사전 분포보다 두 lag 모두 유의하게 높지만,
이는 **이번 변경이 기존 GNN을 개선했다거나 뉴스 내용의 추가 가치를 입증했다는 뜻이 아니다.**
기존 뉴스 제거·종목별 사전 분포·LightGBM 대비도 보정 후 유의한 우위는 없었다.
균형 뉴스 제거 대비 양의 유의한 차이도 없었다.
기존 입력 + 균형 손실의 KOSPI 직접 3일은 균형 뉴스 제거보다 −2.977%p였고,
lag 20에서만 Holm p=0.00977로 낮았다. 두 lag 모두에서 확인된 악화라고 주장하지 않는다.

  단일 그룹 fallback, 기사 동일 가중치, 마스킹 및 두 과제의 gradient.

- 세 조건 각각 validation 90,157행의 시드 평균과 저장 앙상블이 정확히 일치.
- 336개 통계 비교를 별도 거래일 집계·수식으로 교차 검증: 최대 오차 `9.99e-16`.
- 원본 데이터·모델·참조 특징 및 학습 코드 해시 검사 통과. 새 test 예측 없음.
- 기존 모델 `66c54ef0207b4783` 유지. 서비스 연결·커밋·push/MR 없음.

입력 포함률 개선과 손실 균형 조정만으로 뉴스 활용의 추가 예측력을 확인하지 못했다.
다음 설계 후보는 기사 공통 임베딩 대신 **대상 기업별 문맥 특징**을 넣고,
직접 기업 예측부터 뉴스 없는 동일 구조와 비교하는 것이다.
한 기사 안에서 기업마다 사건·방향이 다를 수 있는데 현재 구조는 같은 뉴스 벡터를 공유한다.
이는 아직 검증하지 않은 가설이며 개선 보장이 아니다. 이번 실행에서 추가 구조 탐색은 하지 않았다.
