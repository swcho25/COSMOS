## 3. 원문 표본 192쌍 검토

채택 후보 666,282쌍 중 고정 seed와 SHA256 순위로 192쌍(192개 기사)을 재현 가능하게 뽑았다.
64쌍씩 3묶음으로 나눠 원문 전체·기업 정보로 AI 보조 검수했고, 경계 사례를 별도 재검토해 5건을 조정했다.
초기 검수는 AI 에이전트 2개가 128쌍·64쌍을 맡았다. 파일명 및 `reviewer`의 1·2·3은 검토 묶음 번호이며 독립 검토자 3명을 뜻하지 않는다.
원래 B 판정과 최초 검토 파일은 보존했으며 전체 선별 라벨은 수정하지 않았다.

| 최종 표본 검토 | 쌍 수 |
| --- | --- |
| 채택 가능 | 144 |
| 제외 권고 | 33 |
| 판단보류 | 15 |

**144/192(75%)는 이 표본의 AI 보조 검수에서 채택 가능으로 본 비중이다. 전체 선별 정확도·정밀도·재현율·F1이나 GNN 성능이 아니다.**
사람의 정답 라벨을 만들지 않았고, 제외·보류·미처리 집합에서 누락된 좋은 기사는 이번 표본으로 평가하지 않았다.
검토에는 대상 종목코드가 포함됐지만 기존 teacher 프롬프트에는 대상 코드가 없었다. 따라서 teacher와 동일 입력 조건의 비교 평가도 아니다.

| 확인된 사례 | 왜 문제인가 |
| --- | --- |
| `cadence` → Cadence, `메타 정보` → Meta | 일반 용어를 회사로 연결 |
| GM 공장의 지역명 오리온 → 오리온 | 동명 지명과 기업을 혼동 |
| `한화로 약 7조원`, GS 인증 | 화폐 표현·인증 약칭을 회사명으로 연결 |
| 주가 등락 목록·애널리스트 소속·전 직장 | 기업의 구체적인 사업 사건과 단순 언급을 혼동 |
| 그룹 활동·과거 사명 | 대상 발행인 귀속을 원문만으로 확정하기 어려움 |

모든 검토 인용문은 원문에 정확히 존재하고, 표본 192쌍은 최종 병합 DB의 같은 입력 해시·원문과 연결됨을 확인했다.
제품·사업 관련 정보의 채택은 실제 주가 변동이나 경제적 중요도를 보장하지 않는다.

병합 자료와 원문은 준비됐다. 먼저 위에서 확인한 일반명사·동명 지명·등락 목록 오탐, 그룹·과거 법인 귀속을 다룬 뒤 그래프에 반영할 집합을 확정하는 것이 타당하다.
