# GNN 정체 원인을 구분하는 세 가지 대조 실험

2026-09-15. 사용자 승인: "그럼 3번 더 해봐".
결과 경로는 `artifacts/news_three_comparisons_20260915`다.
새 기사 추가 실험의 38.8541%가 기존 GNN 39.6143%를 넘지 못해, 다음 세 가설을
한 요소씩 비교한다. 이번 세 비교가 끝나면 결과에 맞춰 설정 탐색을 중단하거나 후속 자료
보강을 결정한다. 65%가 나올 때까지 임의로 조건을 바꾸는 탐색이 아니다.

## 데이터와 목표

`news_augmentation_20260915_v2`의 20,458학습 기사/30,873직접 기업 쌍을 그대로 참조한다.
본문 정제·시점 조건·종목 순서·가격 라벨·분류 경계·PCA·7개 연도 그래프와 원래 기사/쌍을
수정하지 않는다. 원천 및 기존 모델 산출물까지 SHA-256으로 동결한다.

목표는 원래 **2023년 검증 직접 4,813쌍**에서 시장×1/3일을 동일 가중하고 각 셀의 거래일을
동일 가중한 방향 정확도 65%다. 정제로 예측하지 못한 70쌍도 오답으로 포함한다.
공통 예측 4,743쌍의 정확도는 보조로 함께 기록한다. 기업·기사·평가 기간을 골라 점수를 높이지 않는다.
이미 여러 번 사용한 검증 기간에서의 **탐색적 비교**이며 독립 미래 성능으로 소개하지 않는다.
특히 정확도 선택은 이 검증 정답을 직접 사용하므로 그 구간 점수 향상을 새 기간 개선으로 볼 수 없다.

## 세 가지 비교

| 비교 | 변경한 요소 | 고정한 요소 |
|---|---|---|
| 1. 그래프 정보 전달 | 기업 간 엣지 유지/제거 | 기업 노드, 정적 특징, 뉴스, 후보, 손실, 선택 규칙 |
| 2. 체크포인트 선택 | 복합 검증 손실 최소/전체 방향 정확도 최대 | **정확히 같은 학습 경로와 후보 epoch** |
| 3. 학습 가중치 | 방향 CE의 기사별 가중/시장·거래일 균형 가중 | 강도 손실, 뉴스, 그래프, 정확도 선택 규칙 |

1번은 GAT의 자기 연결과 잔차층을 유지한다. 현재 그래프를 통한 기업 간 메시지 전달 효과를
판정하며, 모든 GNN 구조의 적합성을 판정하지 않는다. 후보 기업과 정적 노드 특징도 유지하므로
그래프로 후보를 검색하는 기능의 효과를 없앤 비교는 아니다.

2번은 학습 1회에서 선택기 두 개를 관찰한다. 조기 종료는 계속 기존 복합 val 손실이 결정한다.
최대 30 epoch, 최소 개선 1e-5, patience 6이며 멈추는 마지막 epoch도 두 선택기의 후보에 포함한다.
정확도는 같은 val forward의 예측으로 계산한다. 최소 개선 1e-8, 동률은 이른 epoch를 선택한다.
정확도 선택만을 위해 더 오래 학습한 실험이 아니며, 학습 길이의 효과와 섞지 않는다.

3번의 방향 CE는 학습 쌍마다 다음 가중치를 준다. 두 기간 모두 같은 유효 쌍을 갖는 현재
데이터 계약에서 시장·기간별 질량은 동일하고 그 안의 각 거래일도 동일하다.

```
학습 기사 수 / (4 × 해당 시장 학습 거래일 수 × 해당 시장·거래일의 유효 쌍 수)
```

CE×가중치를 모두 더해 배치 **기사 수**로 나눈다. 배치 안 가중치 합으로 다시 정규화하지 않는다.
강도 Smooth L1은 원래 기사별 동일 가중을 유지한다. 검증 복합 손실도 기존 함수 그대로다.
학습 가중치는 학습 자료의 시장·날짜·유효 쌍 개수로만 결정하며 가격 정답 값이나 val/test 빈도를 쓰지 않는다.
KOSPI 14,482쌍/1,268날짜, NASDAQ 16,391쌍/1,504날짜다.
float32 가중치의 float64 누적 합은 20,457.9999062로, 기사 수 20,458과의 차이는 반올림 오차다.

## 학습 횟수와 대조군

| 학습 조건 | 기업 간 엣지 | 본문·감성 | 방향 학습 가중치 |
|---|---|---|---|
| standard | 유지 | 유지 | 기존 |
| no_edges | 제거 | 유지 | 기존 |
| no_content | 유지 | 0 | 기존 |
| balanced | 유지 | 유지 | 시장·거래일 균형 |
| balanced_no_content | 유지 | 0 | 시장·거래일 균형 |

각 3시드로 **15회 학습**한다. 각 학습 경로에서 loss/accuracy 두 선택기의 결과를 저장하므로
체크포인트는 **30개**다. 이를 30회 독립 학습이라고 세지 않는다.
뉴스 제거에도 기업 ID·언급 정보·그래프는 남는다. no_edges에 대응하는 별도 뉴스 제거 모델은
없으므로 no_edges의 결과로 그 설정에서 뉴스 내용의 추가 이득까지 주장하지 않는다.
모든 조건은 GATv2 hidden64/dropout.15, batch24, AdamW lr.0008/weight decay.001을 유지한다.

핵심 대조 8개(그래프 1, 선택 2, 가중치 2, 뉴스 내용 3)와 세 후보의 원래 GNN·종목 빈도·시장
다수 클래스 비교 9개를 학습 전에 고정했다. 시장×기간 4개를 곱해 **시차별 68개 비교**다.
원래 4,813쌍을 사용하는 거래일별 정확도 차이에 HAC lag5/20을 적용하고 각각 Holm 보정한다.
총 136행의 통계와 13모델×4셀=52행의 지표를 저장한다. 이전 실험의 공통 4,743쌍 HAC와는
통계 모집단이 다르므로 p값을 직접 섞지 않는다. 이번에는 목표 점수와 동일한 모집단에서 비교한다.

강도 MAE는 유지 쌍에서 보조로 보고한다. 정확도 상승과 강도 오차 변화가 함께 있는지 확인하되,
보조 지표가 좋아졌다는 이유로 방향 정확도 목표를 달성했다고 표현하지 않는다.

## 결과 — 세 비교 완료

15회 학습·평가가 **1,685.9초(약 28.1분)**에 정상 종료했다.
아래 정확도는 세 시드의 예측 확률을 평균한 앙상블을 원래 4,813쌍에서 채점한 값이다.

| 비교 | 기준 | 변경 후 | 차이 |
|---|---:|---:|---:|
| 기업 간 연결 제거 | standard_loss 38.9242% | no_edges_loss 38.3178% | −0.6064%p |
| 정확도로 체크포인트 선택 | standard_loss 38.9242% | standard_accuracy 38.8788% | −0.0454%p |
| 방향 CE에 시장·거래일 균형 적용 | standard_accuracy 38.8788% | balanced_accuracy 39.6142% | +0.7354%p |

이 세 대조의 모든 시장×기간 셀에서 HAC lag5/20의 Holm 보정 p가 0.05보다 컸다.
그래프 비교의 최소 보정 p는 lag5 0.2693 / lag20 0.3247이고, 선택·가중치 대조는 모두 1이다.
따라서 **확실한 개선을 입증한 비교는 없다.** 가중치 조정의 점추정 상승은 기록하되,
새 기간에서 재현된 개선이나 65% 달성으로 표현하지 않는다.

원래 GNN은 **39.6143%**, 이번 balanced_accuracy는 **39.6142%**다.
차이는 −0.0000588%p로 사실상 같다. 원래 모델보다 좋은 새 모델을 확보했다는 결론은 아니다.
같은 가중치·선택 기준에서 뉴스 본문·감성을 제거한 모델은 **39.1083%**다.
뉴스 포함 쪽의 +0.5060%p 차이도 네 셀·두 시차에서 보정 p=1로 우위가 확인되지 않았다.
**세 후보 모두 65% 미달이며 원래 모델을 유지한다.**

정확도로 선택했는데 앙상블 정확도가 낮아진 것은 계산 오류를 뜻하지 않는다.
선택은 각 시드의 정확도로 하지만 최종 모델은 확률을 평균한 뒤 argmax한다.
개별 시드 정확도가 좋아져도 이 비선형 결합 결과가 반드시 좋아지지는 않는다.
이번 standard의 loss 선택 epoch는 2/2/4, accuracy 선택은 6/7/4였다.

### 검증과 다음 판단

전체 검증이 정상 종료했다(`reload_verification.json`).

- 원천 계보·입력·기존 모델 해시, 7,242개 추가 가격 정답, 7개 그래프, 원래 평가 모집단 재확인.
- 시장·기간·거래일 학습 가중치와 미응답 포함 선택 가중치를 원래 행에서 독립 재구성.
- 방향 손실과 기울기는 가중치에 맞고, 강도 손실·기울기는 기존 기사별 방식과 같으며 마스크 밖은 0임을 확인.
- **체크포인트 30개×검증 기사 6건 = CPU 재생 180회**: 최대 예측 차이 **1.19×10⁻⁷**.
- 선택된 epoch의 전체 4,743쌍 저장 예측으로 정확도 재계산: 차이 **0**.
  같은 예측으로 복합 검증 손실을 독립 계산한 최대 차이 **5.70×10⁻⁸**.
- 두 선택기의 동일 후보 epoch·동률 정책·조기 종료와 3시드 확률 평균 일치 확인.
- **지표 52행**, 최대 차이 **8.33×10⁻¹⁷**; **HAC 136행 및 Holm 보정**, 최대 차이 **3.33×10⁻¹⁶**.
- 실행 산출물 manifest의 **99개 파일 해시** 일치 확인.

미선택 epoch의 예측 전체는 저장하지 않았으므로 해당 epoch의 정확도는 학습 이력으로만
확인한다. 모든 epoch의 예측을 독립 재생했다고 주장하지 않는다. 검증 통과는 실행·계산의
일관성을 확인한 것이며, 사건 주체의 사람 검수나 최초 발행시각·법인 식별 인증을 대신하지 않는다.

이번 세 비교를 끝으로 현재 자료에서의 추가 설정 탐색을 중단한다. 우선 확보할 자료는
원천별 최초 발행/수정시각 정의, 과거 기업·별칭 이력, 가격 정답을 보지 않고 검수한 사건
주체·시점 표본이다. 해당 자료 없이 GNN 층 수나 학습 횟수만 늘리는 실험은 이어가지 않는다.
기업 간 연결 제거가 성능을 높이지 않았다는 사실만으로 GNN에 문제가 없다고 확정하지도 않는다.
추후 개선 후보는 고정한 설정으로 새로운 기간에서 검증해야 한다.
