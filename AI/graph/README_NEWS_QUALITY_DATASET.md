`README_CURRENT_EVENT_EXPERIMENT.md`에 있다. 새 모델 38.18%, 기존 39.61%로
65% 미달·원본 유지다. 아래 문서는 재학습 이전의 원천 복원·후보 확장 단계 기록이다.

2026-09-15. 이전 15개 GNN 실험이 65%에 도달하지 못해 입력 데이터 개정을 시작했다.
이번 작업은 데이터·검수 자료 준비다. 모델 재학습, 기존 검증 정답 변경, 운영 연결은 포함하지 않는다.

## 새로 확인한 사실

기존 `spark/export_impact_news.py`는 날짜만 추출했다. HDFS 준비본 자체에는
`published_at_raw`, `published_at`, `published_timezone`, `collected_at`, 기사 URL과 원천 위치가 있었다.
따라서 이전 코드의 "원천에 날짜만 있다"는 설명은 부정확했다. 해당 docstring을 정정했다.
원래 기사·모델·가격 정답을 덮어쓰지 않는다.

전체 HDFS 준비본 13,259,404행을 원천별로 집계했다. 고유 기사 수가 아닌 원천 행 수다.

| 구분 | 원천 행 | 시간대 오프셋이 있는 normalized 시각 | 기사 URL 있음 |
|---|---:|---:|---:|
| 국내 | 11,149,136 | 490,003 | 11,149,136 |
| 해외 | 2,110,268 | 0 | 2,110,268 |

49만 행은 필드 형식 집계이며 발행시각 정확성을 전수 검수한 숫자는 아니다.
해외 S3 예시에서는 날짜에 자정이 붙어 있었다. 다른 해외 원천은 시각은 있지만 시간대가 없었다.
국내 ZIP/SSAFY 원천의 많은 시각도 시간대가 명시되지 않았다.
56개 원천/정규화 유형 예시를 확인했고 전체 집계와 별도로 보관했다.

해외 S3 원본 `stanford-oval/part-0004.parquet`도 별도 복사해 확인했다.
행 2580의 `publish_date`는 `2018-02-10`, `crawl_date`는
`2018-02-10T08:31:44+00:00`였다. 발행 날짜와 수집시각은 별개이며,
이 예시의 수집시각으로 정확한 발행시각이 복원되는 것은 아니다.
원본 발췌 파일과 SHA256 검증은 `artifacts/news_quality_source_20260915`에 있다.

기존 v2의 29,827기사에서 명시적인 시간대와 원문 시각이 함께 있는 복원 후보는
train 국내 3,083건, val 국내 24건, test 국내 3,065건이었다. 해외에는 없었다.
이 후보는 원천 필드 간 일관성 검사 결과이며 원 발행자의 확인이나 역사적 웹페이지 검증은 아니다.

## 파이프라인

1. `spark/export_news_quality.py`: 원천을 읽어 전체 시각 집계와 기존 32,621개 추출 ID의
   메타데이터를 복원한다. 학습 기간 2017~2022년에서 금융 사건 키워드가 제목·본문 앞부분에
   있고 기업이 연결된 기사를 국내/해외·연도별 최대 5,000건씩 결정적으로 추출한다.
2. `news_quality.py`: 시각 근거를 검사하고, 기업명과 금융 사건 표현이 같은 문장에 있는
   짧은 원문 근거를 추출한다. 미래 주가·방향 정답·모델의 오답 여부는 사용하지 않는다.
3. `prepare_news_quality.py`: 알려진 주가 위젯/추천 피드 제거, 기업명 재검색, 동일 문장 사건
   확인, 검증·테스트와의 중복 차단 후 새 후보 집합과 검수 자료를 만든다.
4. `verify_news_quality_dataset.py`: 원본 해시와 기존 필드 전체 보존, 새 후보의 학습 기간,
   중복·검증 겹침, 전체 기업 언급/인용 위치, 미검수 상태를 검사한다.

HDFS 원천 데이터는 수정하지 않는다. 사용자 승인 후 프로젝트 서버 작업 디렉터리에서
Spark를 실행하고 별도 로컬 파일로 추출했다. Spark 자체의 기존 이벤트 로깅 설정은 사용한다.
기존 추출 스크립트의 동작은 재현용으로 유지하고 새 스크립트가 메타데이터를 보존한다.

중복 검사는 원천 ID, 원문/정제 본문의 NFC·공백 정규화 해시, 원천 canonical URL을 사용한다.
후보끼리도 같은 기준으로 중복을 제거한다. 모든 의미적 유사 기사와 부분 전재를 잡는 검사는 아니다.
새 기사 중 원래 학습 기사와 겹치는 건수와 실제 추가 후보 수를 별도로 센다.
원래 학습 기사와의 겹침도 ID·원문/정제 본문 해시·canonical URL을 모두 확인한다.

## 시각과 학습 계약

- 시간대 없는 값을 국내/해외라는 이유만으로 KST/UTC로 정하지 않는다.
- 원문이 날짜뿐이면 정규화된 자정을 정확한 발행시각으로 사용하지 않는다.
- 날짜·시각 충돌, 수집시각이 발행시각보다 이른 경우, 잘못된 원천 시각을 구분한다.
- 서머타임의 중복·존재하지 않는 지역 시각은 오프셋이 없으면 채택하지 않는다.
- 명시적 수집시각은 발행시각을 복원하지 못해도 별도로 보존한다. 수집시각은 발행시각과 다르다.
- 날짜만 쓰던 기존 `available_at`과 모든 기존 필드는 유지한다. 복원 후보는
  `publication_time_audit`에 별도로 넣는다. 시각을 바꾸는 실험은 새로운 정렬 프로토콜이 필요하다.
- 새 후보의 주 모델 입력 텍스트는 `title`, `body`뿐이다. 원천 `metadata_json`의
  일부 payload에 있는 감성/관계/영향 라벨은 미검증 정보로서 보존만 하며 정답과 모델 입력에 쓰지 않는다.

새 후보는 `label_status=unlabeled`, `human_review_status=pending`이다.
같은 문장에 기업명과 실적·계약 등의 표현이 있다고 실제 사건 주체까지 확정되지는 않는다.
자동 규칙을 사람의 독립 검수나 금융 감성 정답으로 소개해서는 안 된다.
후보의 `companies`와 언급 횟수는 정제 후 확인한 언급으로 다시 만들고 원본은 `source_companies`에 둔다.
`event_tickers`와 일반적인 `verified_tickers`는 구분한다.

## 검수 자료와 남은 데이터 확인

국내/해외 × 6개 학습 연도별로 유지 후보 최대 5개, 제외 후보 최대 2개를
독립 해시 순서로 뽑는다. 가격 결과와 모델 예측을 넣지 않는다.
`HUMAN_REVIEW.md`는 읽기용이고 `human_review.json`에는 검수자, 기업 일치 여부,
실제 기업 사건 여부, 본문 오염, 시각 근거, 메모를 기록한다. 아직 사람이 검수하지 않았다.

원천 제공자에게 확인할 항목:

| 원천 | 현재 확인 상태 | 필요한 근거 |
|---|---|---|
| mysql_domestic | UTC가 명시된 값 존재 | published_at_iso가 최초 발행/수정 중 무엇인지, 당시 본문 보존 여부 |
| s3_kr_hankook / s3_kr_mk | +09:00가 명시된 값 존재 | 수집 당시 본문과 최초 발행시각을 보존했는지 |
| 국내 SSAFY/ZIP | 현지 시각처럼 보이지만 시간대 없음 | 원천별 시간대·최초 발행/수정 의미를 명시한 수집 규약 |
| mysql_overseas / mysql_fundus | 시각은 있지만 시간대 없음 | 공급자별 UTC/현지 시각 규약과 발행/수정 의미 |
| s3_us | 날짜만 있는 발행일 예시, 오프셋 있는 수집시각 | 원본 CCNews/WARC 등에서 발행시각 복원 가능 여부와 수집시각의 정의 |

기업의 과거 법인 정체성, 정제 원문 기반 과거 그래프 재구축, 새로운 후속 평가 기간 확보는
아직 완료하지 않았다. 현재 데이터 개정만으로 65% 달성 또는 성능 향상을 주장하지 않는다.

자동 후보 발췌 검토에서 자료 제공사(TRI)를 실적 사건 주체로 잡거나,
과거 인수 이력을 현재 인수 사건처럼 잡는 사례를 확인했다.
`NEWS_QUALITY_SPOT_CHECK.md`에 실제 인용으로 확인한 7개 사례를 정리했다.
이는 Codex의 정성 검토이며 사람 검수 완료 건수나 전체 후보의 정밀도가 아니다.
현재 후보 전체를 검증된 직접 사건으로 취급해 바로 학습에 넣으면 안 된다.

## 실행

로컬에서는 `AI/ner/.venv/Scripts/python.exe`, `PYTHONUTF8=1`을 사용한다.
스크립트 출력 경로는 새 폴더여야 한다.

```powershell
$env:PYTHONUTF8='1'
$env:PYTHONUNBUFFERED='1'
AI/ner/.venv/Scripts/python.exe AI/graph/tests/test_news_quality.py
AI/ner/.venv/Scripts/python.exe AI/graph/tests/test_quality_isolation.py
AI/ner/.venv/Scripts/python.exe AI/graph/prepare_news_quality.py --export AI/graph/artifacts/news_quality_source_20260915 --out AI/graph/artifacts/news_quality_dataset_20260915_v2
AI/ner/.venv/Scripts/python.exe AI/graph/verify_news_quality_dataset.py --dataset AI/graph/artifacts/news_quality_dataset_20260915_v2
```

시각·동일 문장·원문 인용·공백 중복 회귀 검사 6개와 전체 파이프라인 격리 검사 1개가 통과했다.
격리 검사는 검증 기사의 날짜/ID를 위장한 본문, 추천 피드, 중복 기사와 비사건 문장을 주입하고
기존 검증 기사가 학습 후보로 들어가지 않는지 확인한다. 가격 파일은 의도적으로 읽을 수 없는
더미로 두어 이 단계가 가격 정답을 사용하지 않는지도 검사한다.
기존 학습 URL에 다른 ID·본문이 붙어도 신규 기사로 세지 않는 회귀 조건도 포함한다.

서버의 첫 추출은 정규식이 기업 조인보다 먼저 적용돼 느려지는 실행 계획을 확인했다.
완료된 국내 26,027행과 메타데이터를 보존하고, 기업 조인 후 짧은 본문을 캐시해 해외 추출을
재개했다. 선택 키워드와 해시 순서는 유지했고 국내 파일 접두부의 SHA256 일치도 검사했다.
중단 전 국내의 전체 적격 모집단 집계는 복구하지 못했다. manifest의
`domestic_eligible_count_available=false`를 유지하며 국내 추출률은 주장하지 않는다.
해외에서 기업 연결 후 정규식 대상으로 읽은 행은 205,768개다.

## 실제 산출 결과

최종 후보 경로: `artifacts/news_quality_dataset_20260915_v2`.
첫 로컬 결과 `news_quality_dataset_20260915`와 당시 코드 스냅샷도 보존했다.
첫 결과는 기존 학습 URL과 같은 1건을 신규로 세었으므로 신규 건수 26,821은 폐기한다.
최종 결과는 URL까지 반영해 26,820건이며 유지 후보 자체와 평가 모집단은 바뀌지 않았다.

| 항목 | 국내 | 해외 | 합계 |
|---|---:|---:|---:|
| 서버에서 추출한 후보 | 26,027 | 28,656 | 54,683 |
| 로컬 규칙을 통과한 후보 | 16,120 | 11,906 | 28,026 |
| 제외 | 9,907 | 16,750 | 26,657 |

- 유지 후보 중 기존 학습과 ID/본문/URL이 겹치는 기사 1,206건, 추가 후보 26,820건.
  기존 학습 전체와 합쳐 모델용 데이터셋을 만든 상태는 아니다.
- 제외 사유: 동일 문장 사건 없음 24,161건, 추천 피드 2,024건, 짧은 정제 본문 255건,
  기업 재확인 실패 199건, 후보 중복 18건. 먼저 적용된 제외 사유 하나씩 집계했다.
- 기존 val/test와 겹쳐 제외된 후보 0건. 이는 명시한 ID/본문 해시/URL 기준이며 의미적 유사 기사 보장은 아니다.
- 유지 후보의 시각: 국내 명시 시각 후보 3,499건, 국내 시간대 미확인 12,621건,
  해외 날짜만 확인 11,906건. 기존 기사 복원 후보 6,172건과 별개 모집단이므로 합산하지 않는다.
- 사람 검수 자료 84건(유지 60, 제외 24), 사람 검수 완료 0건.
- 새 가격 정답 생성·그래프 재구축·GNN 재학습·새 정확도 측정 없음. 기존 모델과 기존 평가 필드는 보존했다.

`completion.json`은 집계, `verification.json`은 전체 산출물 검사 및 해시,
`human_review.json`/`HUMAN_REVIEW.md`는 검수 자료다.
원천 다운로드 검사는 source 폴더의 `transfer_verification.json`에 있다.
전체 검증을 통과했다: 기존 기사 29,827건 필드 보존, 원천 해시 일치,
후보 28,026건의 학습 기간·ID/본문/URL 중복 및 val/test 겹침 0건,
원문 근거 위치 86,124개 일치. 신규 여부를 원천 본문과 기존 학습 URL까지 재계산했다.
`revision_verification.json`은 첫 결과와 비교해 신규 여부 1건만 변경됐고
검수 패키지와 모든 나머지 후보 필드는 같음을 기록한다.
