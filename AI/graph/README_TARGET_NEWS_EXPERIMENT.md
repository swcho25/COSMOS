# 기업별 뉴스 입력 감사와 직접 기업 GNN 실험

2026-09-15. 사용자 목표는 방향 정확도 0.65다. 목표를 맞추기 위해 정답 정의나
평가 구간을 바꾸지 않는다. 이 문서의 실험은 연구용이며 운영 모델 교체와 서비스 연결을 포함하지 않는다.

## 무엇을 측정하는가

기존 v2와 같은 **시장 대비 수정주가 수익률의 하락·중립·상승 3분류**다.
뉴스 이용 가능 시점 이후 첫 종가를 기준으로 1거래일·3거래일 수익률을 구하고,
같은 기간 실제 KOSPI/NASDAQ Composite 수익률을 뺀다. 학습 구간으로 정한 중립 경계를 유지한다.
좋은 뉴스인지 분류하는 문제와 다르며, 뉴스가 일으킨 인과 효과의 정답도 아니다.
첫 기준 종가 이전의 즉각적인 반응은 이 정답에 포함되지 않는다.

2023년 검증 구간의 직접 언급 기업만 평가한다. 시장 2개 × 기간 2개 각각에서
거래일별 정답률을 구한 후 거래일에 동일 가중치를 주고, 네 점수를 평균한다.
기존 여러 실험에서 재사용한 검증 구간이므로 새로운 독립 테스트 성능으로 표현하지 않는다.

**65%의 주지표는 기존 직접 기업 4,813쌍 전체**다. 입력 오류로 예측하지 않은 70쌍도
오답/미응답으로 포함한다. 살아남은 4,743쌍의 조건부 정확도는 보조 지표다.
두 지표가 모두 0.65 이상인지 확인하며, 표본을 제외해서 목표 달성을 만들지 않는다.
원래 실행기의 `completion.json`에는 조건부 목표 판정만 들어 있으므로 최종 판정은
`reload_verification.json`의 전체 모집단 점수와 `user_target_met`를 사용한다.
이 보완 기준은 특징 생성 중, 학습 결과를 보기 전에 `goal_metric_protocol.json`에 고정했다.

## 100쌍 입력 감사

`audit_target_news.py`는 train/val × KOSPI/NASDAQ마다 25개씩 총 100개의 서로 다른
기사에서 직접 기업 1개를 선택한다. 고정 SHA256 순서를 사용하며 가격, 정답, 예측,
모델의 오답 여부로 뽑지 않는다. 제목과 대상 기업 발췌를 모두 읽고 의심 사례의 전체 본문을
추가 확인했다. 에이전트의 정성 검토이며 사람의 독립 검수나 전체 100개 본문 정독을 뜻하지 않는다.
원문 인용을 대조하고 검토 파일을 고정한 뒤 가격 결과를 결합했다.

| 분류 | 건수 |
|---|---:|
| 부수적 언급 | 34 |
| 기업 사건 | 29 |
| 일상적 정보 | 12 |
| 전망 | 10 |
| 주가 동향 보도 | 5 |
| 과거 사실 | 4 |
| 다른 대상을 기업으로 오인 | 3 |
| 삽입 피드 오염 | 2 |
| 과거와 현재 기업 정체성 문제 | 1 |

기존 256토큰 입력 밖에 대상 기업이 있던 사례는 40개였고, 원문에서 문자 그대로
재확인하지 못한 기업은 2개였다. 층화한 소규모 표본이므로 전체 데이터의 오류율로 일반화하지 않는다.

발견 예시:

- 2017년 기사 끝의 독립된 `관련 뉴스` 피드에 IFA 2026 및 기아 관련 제목이 붙어 있었다.
- CNBC의 반복 `read more` 추천 피드에서만 Comcast가 등장했다.
- 일본 글로비스대학을 현대글로비스로, Apple Valley라는 지명을 Apple로,
  일반 단어 workday를 Workday 기업으로 연결한 사례가 있었다.
- 현대·기아차 같은 묶음 표기나 짧은 은행 약칭은 기존 기업 정보와 재검색 결과가 일치하지 않았다.

주가 보도를 제외한 명확한 긍정/부정 35쌍에서 문장 의미와 지연 수익률 방향이 같았던 것은
1일 13개, 3일 16개였다. 이는 가격 정답 오류율이나 감성 분류 정확도가 아니다.
독립 계산기로 100쌍의 가격 정답 200개를 다시 계산했으며 최대 절대 차이는
6.80e-9였다. 뉴스 이용 가능 시각부터 기준 종가까지 중앙값은 15.5시간이었다.
계산 일치가 뉴스와 가격의 인과 관계나 원래 발행시각의 정확성까지 보증하지는 않는다.

## 변경과 대조군

`target_news_features.py`에서 기존 정제에 추가로 독립된 `관련 뉴스` 이후를 자르고,
반복 `read more` 피드가 있는 기사는 격리한다. 알려진 동음이의 표현을 좁은 규칙으로
거르고 기업명을 다시 확인한다. 이 규칙은 완전한 본문 추출기나 기업 판별기가 아니며,
문맥이 부족한 올바른 언급을 제외할 수도 있다. 유효하지만 부수적인 언급은 그대로 둔다.
원본 기사·기업 사전·운영 매처는 수정하지 않는다.

각 기업마다 검증된 기업명을 접두어에 명시하고, 본문에서 해당 기업 주변 문맥을 선택한다.
제목에만 기업명이 있어도 본문 사건이 들어오게 한다. 임베딩 256토큰, 감성 128토큰을 지키며
접두어의 이름만으로 원문 기업명 포함률을 높였다고 계산하지 않는다.
동일한 고정 다국어 인코더와 금융 감성 모델을 사용하고 PCA 64차원은 학습 특징에만 맞춘다.

`TargetNewsGAT`는 기사별 공통 벡터 대신 노드별 문맥을 입력받는다.
기존 2층 GATv2의 파라미터 구조를 유지하고, 직접 기업에만 뉴스 정보를 주입한다.
모든 그래프 노드는 메시지 전달에 남지만 손실과 이번 평가는 확인된 직접 기업에만 적용한다.

| 실험군 | 입력 | 학습 |
|---|---|---|
| target | 기업마다 자신의 문맥 | 3시드 |
| pooled | 같은 기사의 기업별 특징을 평균해 공유 | 3시드 |
| no_content | 텍스트·감성 특징을 0으로 제거 | 3시드 |

동일 그래프, 정답, 입력 적격 조건, 직접 기업 손실을 적용한다. pooled는 target과 정확히
같은 특징의 평균이므로 기업별 배치 효과를 분리해 비교한다. 은닉 64, dropout 0.15,
AdamW 학습률 8e-4, weight decay 1e-3, batch 24, 최대 30 epoch, patience 6을 고정했다.
검증 손실로 각 시드 체크포인트를 선택한 뒤 확률을 평균한다.

| 구간 | 시장 | 기존 직접 쌍 | 유지 | 제외 |
|---|---|---:|---:|---:|
| train | KOSPI | 12,170 | 11,943 | 227 |
| train | NASDAQ | 15,986 | 15,312 | 674 |
| val | KOSPI | 2,060 | 2,029 | 31 |
| val | NASDAQ | 2,753 | 2,714 | 39 |

총 특징은 33,276개이며, 학습 가능한 라벨이 없는 유효 언급의 특징도 포함해 쌍 수와 다르다.
PCA는 이 중 학습 기사에 속한 27,879개 특징으로 맞췄다. 생성 후 검사에서
원문 대상 기업 포함률은 임베딩·한국어 감성·영어 감성 각각 100%였고,
최대 입력 길이는 각각 254·126·126토큰이었다. 검증된 언급만 남긴 모집단의 수치이며
기존 4,813쌍 모두를 복구했다는 의미는 아니다.
새 test 특징과 예측은 생성하지 않는다. 과거 그래프는 기존 스냅샷을 보존하므로
정제한 기사로 그래프를 재구축하거나 과거 기업 정체성을 전면 재감사한 실험은 아니다.

기존 GNN, 균형 손실 GNN, 균형 뉴스 제거, 다수 클래스, 기업별 통계, stage2를
동일한 유지 표본에서 비교한다. target 대 8개 기준선 × 네 셀의 거래일 단위 차이에
HAC lag 5/20을 적용하고 각 lag의 32개 비교에 Holm 보정을 한다. 탐색적 검증 결과다.

## 재현과 검증

아티팩트는 `artifacts/news_target_audit_20260915/`와
`artifacts/news_target_experiment_20260915/`에 있다. 원본 학습 폴더를 덮어쓰지 않는다.
PowerShell에서 저장소 루트를 기준으로 실행한다. 실험 출력 경로는 반드시 새 폴더여야 한다.

```powershell
$env:PYTHONUTF8='1'
$env:PYTHONUNBUFFERED='1'
AI/ner/.venv/Scripts/python.exe AI/graph/tests/test_target_news.py
AI/ner/.venv/Scripts/python.exe AI/graph/experiment_target_news.py --out AI/graph/artifacts/news_target_experiment_NEW
AI/ner/.venv/Scripts/python.exe AI/graph/verify_target_news.py --experiment AI/graph/artifacts/news_target_experiment_20260915
```

정제·동음이의어·문맥 선택·GAT 입력 동등성/분리 테스트 4개가 통과했다.
`verify_target_news.py`는 원본/실행 코드/특징 해시, 원문 6쌍의 인코더 재생,
9개 체크포인트 CPU 재생, 전체 검증 예측의 앙상블/행 정렬, 통계 64개 독립 계산과
전체 직접 모집단의 목표 점수를 검증한다. 모든 원문의 인코더를 다시 돌리는 검사는 아니다.

## 결과

9개 학습과 재로딩 검증을 완료했다. 특징 생성과 학습에 1,847초(약 30.8분)가 걸렸다.

| 모델 | 유지 4,743쌍 정확도 | 원래 4,813쌍 정확도 |
|---|---:|---:|
| 기존 GNN | 39.53% | 39.61% |
| 기업별 문맥 target | 39.09% | 38.56% |
| 기사 공통 문맥 pooled | 38.78% | 38.25% |
| 뉴스 제거 no_content | 39.13% | 38.59% |

원래 모집단 열에서 새 세 모델의 70개 미응답은 오답으로 처리했고,
기존 모델은 4,813쌍 모두의 기존 예측을 사용했다. 유지 표본에서 기존 균형 뉴스 제거는
40.09%, 기업별 통계는 39.10%, stage2는 39.45%, 다수 클래스는 34.77%였다.

목표 65% 미달이다. target의 no_content 대비 차이는 -0.036%p이며,
모든 시장/기간의 뉴스 제거 및 기존 모델 대비 HAC·Holm 개선은 확인하지 못했다.
일부 셀에서 pooled 및 단순 다수 클래스 대비 차이가 있지만, 이를 뉴스 내용의
추가 예측력 또는 전반적인 개선으로 해석하지 않는다. 기존 운영 후보를 유지한다.

9개 체크포인트 CPU 재생의 최대 차이는 1.19e-7, 6쌍 인코더 재생의 최대 차이는
6.56e-7, 통계 64개 독립 계산의 최대 차이는 3.33e-16이었다.
모든 저장 예측의 행과 앙상블 평균을 대조했고 원본 해시는 유지됐다.
최종 판정 파일은 `reload_verification.json`이며 `user_target_met=false`다.

입력 정제와 기업별 문맥 보장만으로 지연 수익률 예측이 개선되지는 않았다.

뉴스를 제거한 모델과 비교한다. `README_MARKET_CONTEXT_EXPERIMENT.md` 참고.
