# 뉴스·공시 관계와 GNN 연구 산출물

**2026-09-19 후속 범위 확장:** 새 로컬 통합본 `artifacts/kg_integrated_20260919_v3`는119관계·541근거(뉴스177·공시364)다. 기존 v2의112관계에7관계를 추가했다. 전체114,162개 복수 B 후보 기사 재검사 및 신규 후보12개 전문 검토 결과이며, [v5 결과와 제한](README_RELATION_COVERAGE_V5.md)을 확인한다. 기준2026-09-16 최근7D/30D/90D 점수는 기존과 같고, 운영 서비스·HDFS·GNN은 교체하지 않았다. 새 그래프 조회에는 retriever/explainer의 directory 인자로 v3를 명시한다.

이 문서는 2026-09-19에 추가한 **로컬 연구 파이프라인**을 설명한다. 기존 뉴스 모델 번들,
HDFS, 서비스 DB, API를 교체하거나 갱신하는 실행기는 아니다. 진행 및 완료 여부는
`HANDOFF_STORY3.md`의 최신 기록과 각 출력 폴더의 완료 manifest를 확인한다.

## 입력과 관계의 의미

- 부모 KG: `artifacts/kg_grounded_full_20260918_v1`. 선별 후보 483,738기사 중
  뉴스–기업 귀속 검사를 통과한 그래프 뉴스는 219,790기사, 연결은 246,264쌍이다.
- 뉴스 관계: `kg_grounded_relations_v3.py`와 `expand_grounded_relations_v3.py`.
  B가 포함한 기업 후보 사이에서 명시적 관계 역할과 원문 위치를 확인한다.
  기업이 함께 등장했다는 사실만으로 관계를 만들지 않는다.
- 공시 관계: `prepare_grounded_disclosures.py`. 선택된 DART 공시 원문에서 지분보유 및
  공급계약을 추출한다. SEC 입력은 기업–공시 관측이며 SEC 관계 추출 결과는 없다.
- 관계 종류는 `SUPPLY` 공급자→수요자, `INVEST` 투자자·보유자→피투자기업,
  `PARTNER` 협력, `COMPETE` 경쟁이다. 뒤 두 종류는 대칭 관계다.
- **관계, 근거 문장, 독립된 경제 사건은 서로 다른 수량이다.** 여러 기사가 같은 발표를
  반복하거나 여러 공시가 같은 지분보유를 보고할 수 있다. 기존 지분보유는 새 투자 거래와 다르다.

후보 181근거의 문맥 검토에서 166건을 유지하고, 미래 계획·다자 관계·과거 법인 귀속 등이
불명확한 15건을 보류했다. 이는 AI 보조 검수이며, 인간 정답을 이용한 정밀도·재현율 측정은 아니다.
완료한 원본 후보와 검수 정책은 수정하지 않고 별도 파일로 보존한다.

## 통합 결과 읽기

`build_integrated_relation_graph.py`는 입력 manifest와 원문 SHA, 뉴스 인용 위치,
공시의 보고기업 메타데이터와 상대 기업 표기를 검사하고 새 폴더에 다음 파일을 만든다.

| 파일 | 내용 |
| --- | --- |
| `manifest.json` | 완료 표시, 출처·코드 해시, 건수, 범위와 한계 |
| `integrated.sqlite3` | 원문 문서와 관계 근거. GraphRAG의 읽기 전용 입력 |
| `temporal_evidence.jsonl` | 종류·방향·발행/이용가능 시각·기업·인용·URL을 가진 관계 근거 |
| `relationship_scores.jsonl` | 기준 시점의 7D·30D·90D 뉴스/공시 구성 점수 |
| `news_evidence_deferred.jsonl` | 관계 집계에서 제외한 후보와 검토 사유 |

완료 manifest가 없는 폴더는 소비하지 않는다. `verify_integrated_relation_graph.py`는 원문,
시간·방향·기업 참조와 구성 점수의 독립 재계산을 확인한다. 이 검증이 통과했다고 모델의
예측 성능이나 뉴스 관계의 전체 재현율이 검증된 것은 아니다.

초기 통합본 `artifacts/kg_integrated_20260919_v1`은 관계 110개, 근거 530건
(뉴스 166 / 공시 364), 문서 420건이다. 기준 시각은 `2026-09-16T00:00:00Z`다.
이 버전의 최근 90일 뉴스 관계는 0건이므로 뉴스 구성 점수는 모두 NULL이다.
최근 뉴스 원문이 없는 것이 아니라 관계 추출 재현율과 상대 기업 후보 누락 문제가 확인됐다.
추가 보완본이 만들어지면 **새 manifest 경로**를 사용하며, 이 버전의 결과를 바꾸지 않는다.

최종 보완본 **`artifacts/kg_integrated_20260919_v2`**는 관계 **112개**, 근거 **532건**
(뉴스168 / 공시364), 문서422건이다. 최근 기사 2,052건을 다시 검사하고, 독립 문맥 검토로
카카오–LG유플러스 협력과 한화시스템→KAI 지분 매입을 추가했다. KAI는 원래 B의 보류 대상이었고,
해당 기사의 명시적 매입 문장·유일한 별칭·발행 당시 DART 정보를 확인해 **관계 상대만** 복원했다.
기존 B 판정이나 뉴스 감성을 채택으로 바꾸지 않았다.

v2의 7D/30D/90D 점수는 각각 1/9/57행이다. 뉴스 점수가 있는 관계는 30D와90D에서 각각2개며,
나머지는 공시 점수만 있다. **현재 같은 기간·기업쌍·관계종류에 뉴스와 공시가 모두 있는 행은 없다.**
따라서 이 작은 근거 집합만으로 양쪽 가중치를 바꿀 때 점수가 달라지는 사례가 확보되었다고
말할 수 없다. 더 많은 원문 근거를 수집·추출해야 하며 없는 구성 점수를 만들어 넣지 않는다.

## 구성 점수

각 기업쌍·관계종류·기간에서 같은 출처 문서의 중복 인용은 최대 한 번 반영한다.
현재 뉴스의 명시적 관계 근거는 문서 지지 가중치 1을 사용한다.

```text
구성 점수 = 100 × (1 − exp(−문서 지지 가중치 합 / 5))
둘 다 있음: score = 0.5 × news_score + 0.5 × disclosure_score
한쪽만 있음: score = 존재하는 구성 점수
둘 다 없음: 점수 행을 만들지 않음
```

근거가 없는 구성 점수는 `NULL`이다. **이 점수는 문서 근거량을 변환한 관계 점수이며,
주가 수익률·상승 확률·검증된 모델 신뢰도가 아니다.** 이 계산에는 주가 50%가 들어가지 않는다.
사용자 뉴스 가중치 조절은 두 구성 점수가 모두 있을 때 프론트에서 계산할 수 있다.
한쪽이 NULL이면 존재하는 점수를 쓰므로 슬라이더를 움직여도 점수가 변하지 않는다.

## 통합 GraphRAG

프로젝트 루트에서 Python의 모듈 경로에 `AI/graph`를 추가하거나 그 폴더에서 실행한다.
다음은 로컬 산출물을 조회하는 예시다.

```python
from integrated_relation_graph import IntegratedRelationRetriever

reader = IntegratedRelationRetriever("artifacts/kg_integrated_20260919_v2")
result = reader.retrieve(
    "005930", "009150", "INVEST",
    as_of="2026-09-16T00:00:00Z", limit=5,
)
```

기업쌍과 관계종류가 일치하는 뉴스·공시를 검색하며, 각 근거에는 원문 인용, URL, 발행 시각,
이용가능 시각, 출처 종류와 식별자가 포함된다. 공급·투자 관계의 방향을 뒤집어 조회하지 않는다.
관련 기사에 이름이 같이 나왔다는 이유만으로 근거를 대체하지 않는다.

현재 권장 설명기는 **`safe_integrated_relation_explanations.SafeIntegratedRelationExplainer`**다.
네 유형 모두 확인한 관계 종류의 고정 안내와 **정확한 원문 인용·URL**을 반환한다.
공시는 보고기업 메타데이터를 함께 보존한다. 사용법은 `README_SAFE_RELATION_EXPLANATIONS.md`에 있다.
최종112관계의 실제 조회에서 원문·출처와 설명 인용의 일치도 확인했다.

이 정책은 실제 생성 모델을 시험한 결과에 따른 것이다. 기존 `IntegratedRelationExplainer`의
Qwen+NLI 경로는 '카카오와 동맹한 LG유플러스가 AIDC를 짓는다'를 카카오도 함께 건설하는 것으로
확대했는데 NLI가 이를 통과시켰다. 원래 생성·검증 기록을 보존하고, **이번 통합본의 권장 설명에서는
자유 생성문을 받지 않는다.** NLI 점수는 의미 정확도의 보증이 아니다. 기존 생성 경로는 연구용으로만
남겼으며 새 권장 어댑터는 생성기를 호출하지 않는다. 뉴스·공시 근거 검색은 계속 제공한다.

검색 결과는 최신순이며 양쪽 출처를 반드시 하나씩 고르지는 않는다.

## 시간과 학습 경계

- 시간대가 있는 발행 시각은 UTC로 변환한다. 날짜만 있거나 시간대가 불명확하면
  해당 달력날짜가 전 세계에서 끝나는 다음날 12:00 UTC부터 이용 가능하다고 보수적으로 처리한다.
- 공시의 회계 기준일·계약일을 뉴스가 알려진 날짜로 사용하지 않는다.
- `available_at < cutoff`인 근거만 사용한다. 나중에 수집한 역사적 공시를 공개 시각 기준으로
  재생하는 연구이며, 그 당시 실시간 수집이 실제로 가능했다는 증거는 아니다.
- 공시 하나가 과거 지분보유를 보였다고 현재까지 지분이 유지된 것으로 확정하지 않는다.
- GNN 학습과 시세/뉴스 감성, 관계 점수는 다른 출력이다. FinBERT 긍정·부정·중립은 기업 문맥
  감성이며, GNN은 별도 가격 라벨의 시장 대비 1일/3일 방향과 상대 강도를 학습한다.

새 GNN 데이터 준비는 `prepare_grounded_training.py`, 학습·비교는
`train_grounded_news.py`를 사용한다. 학습 2020–2022 / 검증 2023 / 평가 2024–2026이며,
기존 실험에서 이미 본 기간이므로 새로운 블라인드 평가라고 부르지 않는다.
가격 라벨이 없는 기업 입력도 보존하고 감독 손실에서만 제외한다.
뉴스 제거 대조군·추가 관계 제거 대조군을 같은 표본과 3개 시드로 비교한다.
모델 교체 여부는 평가 결과와 별도로 판단하며, 정확도 65% 도달을 보장하지 않는다.

학습 전 전체 입력 문맥을 검사하여 추천·광고가 섞인 기사12건과 시세 표의 시점을 확인하지 못한
기사4건을 별도 임시 격리했다. 시세 표4건이 미래 정보를 포함했다고 확정한 것은 아니다.
학습6기사는 손실과 기준선 통계에서 제외하며, 평가10기사는 기존 정답률 분모에 남겨
미응답으로 처리한다. 해당 기업에 무관한 기사라고 영구 판정하거나 원본을 삭제한 것이 아니다.
정책·16건 원문 검수는 `artifacts/grounded_input_quality_20260919_v1`에 보존한다.

## 운영 반영 전 별도 작업

현재 범위는 로컬 관계·점수·설명 산출물과 GNN 연구 검증이다. 서비스 테이블 적재,
BE/FE 조회 계약 연결, 최신 뉴스 자동 갱신, HDFS 게시, 배포 모델 교체는 별도다.
관계 추출 범위가 한정되어 있으므로 화면의 관계 수와 현재 뉴스/공시 양쪽 점수 지원 여부를
실제 적재 데이터로 확인해야 한다.
