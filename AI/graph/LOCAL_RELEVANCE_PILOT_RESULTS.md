# 로컬 LLM 뉴스 관련성 파일럿 결과 — 2026-09-16

**다운로드·로컬 추론·후보 파일 생성은 완료했다. 현재 모델을 전체 뉴스의 무검수
자동 선별기로 쓰기에는 품질이 부족하다.** 경제적 관련성 후보를 만드는 보조 도구로
사용할 수 있지만, 실제 주가 반응이나 GNN 성능 개선을 입증한 결과는 아니다.

## 실행한 내용

- 모델: `Qwen/Qwen3-4B-Instruct-2507`, revision `cdbee75f17c01a7cc42f958dc650907174af0554`.
- 공식 파일12개, 총8,060,915,998바이트 다운로드. 가중치3개 모두 게시자 SHA256 일치.
- 가중치·패키지는 `local_models/`, 본문·결과는 `artifacts/`에 저장하고 Git 추적에서 제외했다.
- 사용자 프롬프트 원문은 `news_relevance_prompt.txt`에 보존했다. JSON 출력 형식을 추가하고
  모델이 고른 근거 ID에서 코드를 통해 원문을 복원한다. 인용 내용을 모델이 다시 쓰지 않는다.
- RTX4050 Laptop6GB에서 NF4 4비트 추론. 입력은 기사×기업이며 발행 시각·전체 제목·본문·
  대상 기업만 제공했다. 당시 출처가 검증된 기업 프로필은 실제40건 모두 미제공이다.
- 실제40기사·40기업쌍은2020–2022 학습 구간의 균등 구성 개발 표본이다. 별도로 가상8건을
  검사했다. 기존 검증·테스트와 ID·정규 URL·본문 해시 중복은0건이다.
- 최종 실행은 `inference_v4`다. 미래 수익률·정답·참고 판정은 모델 입력에 넣지 않았다.

## 실제40건 결과

| 항목 | 건수 |
|---|---:|
| 로컬 모델의 유효 채택 | 10 |
| 보류 | 30 |
| 명시적 제외 | 0 |
| 채택10건 중 별도 AI 검토도 채택 | 7 |
| 채택10건 중 별도 AI 검토와 충돌 | 3 |
| 보류30건 중 출력 형식 위반으로 강제 보류 | 7 |

형식 위반7건은 모두 최대2개를 넘는 근거 ID를 출력한 경우다. 나머지23건은 모델 자체
보류다. 입력 길이 초과, 생성 중단, 잘못된 JSON은 최종 실행에서0건이었다.
평가기의 `quote_failure_count=7`은 근거 ID 개수 계약 위반도 포함한 집계이므로
이를 '원문에 없는 인용7개'로 해석하면 안 된다.

별도 검토는 모델 출력을 보기 전에 동결한 **다른 AI의 참고 판정**이다. 사람 정답셋이 아니다.
참고 채택18건 중 모델이 채택한 것은7건이고11건은 보류했다. 참고 제외12건 중1건을
잘못 채택했고11건은 보류했다. 참고 보류10건 중2건은 채택,8건은 보류했다.
채택/제외/보류 선택의 일치는15/40건이다. 이를 일반 뉴스 정확도나 주가 예측 정답률로
표현하지 않는다. '두 AI 모두 채택'도 영향 경로 설명 전체가 맞다는 뜻은 아니다.

가상8건은 채택3·보류5·제외0이었다. 의도한 채택3건은 골랐으나 명확히 제외하도록 만든
4건도 보류했다. 전직 기업·기사 속 지시문 등의 가상 반례에서 미채택했다는 사실만으로
실제 전체 뉴스의 오탐률을 보증할 수 없다. 가상 LG전자 전직 직원 사례는 사용자가 언급한
LG유플러스 기사 원문을 직접 검증한 결과가 아니다.

## 속도·실행 검증

최종48쌍의 인코딩·생성·검증 합계449.16초(약7분29초), 실제40쌍은406.84초였다.
실제 쌍당 평균10.17초, 중앙값10.94초, 최장19.92초다. 다운로드·모델 로드·개발·평가
시간은 제외한다. 모델 상주 메모리 약2.60GB, 최대 torch CUDA 할당량은3.46GiB였다.
후자는 전체 전용 VRAM 사용량이나 예약 메모리와 다른 지표다.

초기3회 실행은 인용 변형·반복 또는 Windows의 SDPA 메모리 문제로 중단하고 보존했다.
GQA의 KV를 명시적으로 확장해 efficient 커널을 사용하는 실행 모듈을 추가했다.
동일3,465토큰 기사는69.67초에서4.57초로 줄었다. 이는 실행 속도 개선이며 관련성 품질
개선 수치가 아니다. 커널에 따른 수치 차이가 있어 이전 출력을 섞지 않고48건을 재실행했다.

관련 테스트65개 통과. 전체48쌍의 입력·결과·참고 키 일치, 누락/중복0, 모델·프롬프트·
코드·근거 복원기·attention 코드 SHA 검증을 완료했다. 전체 원문 구간의 재결합도 확인했다.

이 표본 속도를 단순히 곱하면1,300만 기사를 기사당 기업1개씩만 판정해도 약4.2년이다.
이는 모집단 처리 시간의 실측 견적은 아니지만, 이 노트북에서 전량을 무차별 LLM 추론하는
방식이 적절하지 않다는 신호다. 기존 기업 후보·본문 정제로 양을 줄인 후 품질을 확인한
판정기에 넣는 구성이 필요하다.

## 저장 위치와 후속 사용

모든 아래 경로는 `AI/graph/artifacts/local_relevance_pilot_20260916_v1/` 기준이다.

- `inference_v4/results.jsonl`: 실제40+가상8 전체 원출력·검증·시간 기록.
- `inference_v4/semantic_audit_ai.json`: 실제 채택10건 전체의 사후 AI 내용 감사. 정확 인용과 별개인 귀속·시점·인과 문제를 기록하며 원래 판정을 바꾸지 않는다.
- `inference_v4/candidate_pairs.jsonl`: 모델이 채택한 실제10쌍. 충돌3쌍도 포함하므로 최종 학습 목록으로 사용하지 않는다.
- `inference_v4/held_pairs.jsonl`: 보류30쌍. 무관한 기사라는 정답으로 바꾸지 않는다.
- `review_candidates_v4/review_agreed_candidates.jsonl`: 두 AI의 채택 선택이 일치한7쌍.
- `review_candidates_v4/disputed_candidates.jsonl`: 충돌3쌍. 후보와 분리했다.
- `review_candidates_v4/audit.json`: 원문·참고·모델·입력·코드 해시와 선정 근거.
- `evaluation_v4_independent/`: 이번 기준의 독립 AI 검토와 대조한 집계·검토 묶음.
- `evaluation_v4_prior_proxy/`: 이전의 더 좁은 사건 판정과 비교한 별도 참고 집계.
- `inference_v1/`, `inference_v2/`, `inference_v3/`: 중단 이유와 원결과 보존.

사람 검토 완료는0건이고 GNN 라벨 생성·재학습·기존 데이터 교체·서비스 반영은 하지 않았다.
후속으로 기업의 당시 명칭·소유/사업 관계를 보완하고 새 표본을 사람이 검토해야 한다.
선별 정책을 동결한 다음, 통과한 기사×기업 키로 기존 가격 기반 라벨을 생성하고
GNN을 학습·비교한다. 관련 기사에서 주가가 움직이지 않은 경우도 유효한 학습 사례다.
후대 모델의 내재 지식 가능성과 이 개발 표본의 반복 사용 한계도 남아 있다.
