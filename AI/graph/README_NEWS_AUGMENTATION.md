# 기존 학습 범위를 보존한 뉴스 추가 GNN 실험

후속: 사용자 지정 세 비교는 `README_THREE_COMPARISONS.md`에서 15회 학습·독립 검증까지
완료했다. 아래 후속 후보는 이 문서 작성 시점 기록이며, 연결 제거·선택·가중치 비교를 다시
미실행 과제로 취급하지 않는다. 원래 모델 대비 우위와 65% 목표는 후속에서도 달성하지 못했다.

2026-09-15. 결과 경로는 `artifacts/news_augmentation_20260915_v2`다.
직전 사건 필터 실험이 38.18%로 기존 39.61%보다 낮아, 기존 학습을 409기사로 크게
줄인 영향을 다음 가설로 정했다. 성능을 보기 전에 세 조건·평가·통계 비교를 고정했다.

## 데이터와 고정 조건

| 학습 범위 | 기사 | 직접 기업 쌍 |
|---|---:|---:|
| 기존 본문 위생 검사 통과 | 16,966 | 27,255 |
| 기사 시점 이전 가격 관측을 확인한 기존 학습 | 16,965 | 27,252 |
| 동결된 새 사건 기사 | 3,493 | 3,621 |
| 합계 | **20,458** | **30,873** |

기존 학습에서 사건 키워드 유무로 기사를 골라내지 않는다. 기업별 문맥·본문 위생 검사는
이전 `news_target_experiment_20260915`의 캐시를 복원한다. 종목 수도 직전 엄격한 사건
필터 92개에서 기존 위생 범위의 175개로 복원한다. 성능 하락 원인이 이것이었다고 미리
단정하지 않는다. 상세 사전 측정은 `AUGMENTATION_DESIGN_AUDIT.md` 참고.

가격 관측 조건은 정답이 있는 노드뿐 아니라 **모든 학습 텍스트 입력 노드**에 적용한다.
정답 mask가 없어도 그래프 메시지를 전달할 수 있기 때문이다. 기사 이용 가능 시각까지
양수의 유한한 수정종가가 없는 1,048개 입력을 비활성화했고, 실제 정답 제외는 3쌍이다.
가격 이력이 있는 나머지 121개 비지도 입력은 유지한다. 최초 가격 관측일은 IPO 날짜나
법인 정체성의 인증이 아니다. 기존 val 입력을 이 조건으로 지우지는 않는다.
첫 준비본은 정답 노드만 제외한 버전으로 보존했고 학습하지 않았다. 최종 v2는 입력도 제외한다.

새 기사의 원문·선택·가격 정답·특징과 기존 PCA64/분류 경계·강도 척도는 동결한다.
기존 pairs 845,742행의 순서와 값도 그대로 보존한다. 검증은 원래 직접 4,813쌍이며,
기존 위생 검사에서 남은 4,743쌍을 예측하고 미응답 70쌍도 전체 점수에서는 오답으로 센다.
시장×1/3일 네 셀에서 거래일 평균을 계산해 동일 가중 평균한다. 새 test 예측은 만들지 않는다.

그래프는 직전 사건 실험의 7개 연도별 그래프를 바이트 단위로 복사한다. 모든 조건에 동일한
과거 정제 공동언급·전년도 같은 시장 가격상관 그래프를 제공한다. 복원한 넓은 기존 기사로
그래프를 새로 만들지는 않는다. 따라서 조건 간 차이는 이 공통 그래프 아래의 지도학습 자료
추가 효과이며, 새 데이터의 모든 효과를 분리한 결과나 서비스의 모든 관계 유형을 복원한 것은 아니다.

## 학습 비교

| 조건 | 학습 자료 | 뉴스 내용 |
|---|---|---|
| old_full | 복원한 기존 16,965기사 | 기업별 문맥·금융 감성 |
| augmented | 기존 + 새 기사, 총 20,458기사 | 동일 인코더/투영 |
| no_content | augmented와 동일 | 문맥·감성 0, 기업/시장/언급/그래프 유지 |

각 3시드로 처음부터 학습한다. GATv2의 30에폭 상한·patience6·batch24·hidden64·dropout.15,
AdamW lr.0008/weight decay.001과 기사별 CE+Huber 손실은 유지한다.
같은 에폭이라도 기사 수가 늘면 최적화 업데이트 수가 늘어난다. 동일 계산량 비교라고 부르지 않는다.
augmented를 old_full/no_content/기존 GNN/종목 빈도/다수 클래스와 비교한다.
시장·기간별 HAC lag5/20의 각 20개 비교에 Holm 보정을 적용한다.
이 짝지은 통계 검정은 동일하게 예측한 4,743쌍에서 수행한다. 65% 목표 판정은
미응답도 포함한 원래 4,813쌍의 별도 점수로 한다.

기존 검증 기간을 반복해 사용한 탐색 연구다. 뉴스 내용의 예측력을 주장하려면 대조군 우위와
새 기간 평가가 필요하다. 사건 규칙의 잔여 오류·최초 발행시각 계약·과거 법인 식별은 해결됐다고
표현하지 않는다. 서비스 연결·모델 자동 교체·커밋·push/MR은 수행하지 않는다.

## 실행과 검증

```powershell
$env:PYTHONUTF8='1'
$env:PYTHONUNBUFFERED='1'
AI/ner/.venv/Scripts/python.exe AI/graph/experiment_news_augmentation.py --out AI/graph/artifacts/news_augmentation_20260915_v2 --stage prepare
AI/ner/.venv/Scripts/python.exe AI/graph/verify_news_augmentation.py --experiment AI/graph/artifacts/news_augmentation_20260915_v2 --data-only
AI/ner/.venv/Scripts/python.exe AI/graph/experiment_news_augmentation.py --out AI/graph/artifacts/news_augmentation_20260915_v2 --stage train
AI/ner/.venv/Scripts/python.exe AI/graph/verify_news_augmentation.py --experiment AI/graph/artifacts/news_augmentation_20260915_v2
```

prepare는 새 출력 경로를 사용한다. 원래/새 특징 해시와 입력 복원·가격 시점 조건·고정 평가
모집단을 검사한 후 학습한다. 학습 후 9개 CPU 체크포인트 재생, 3시드 평균,
거래일 지표·HAC/Holm을 독립 재계산한다. 새 인코더 학습/추출은 하지 않았으므로 이전에
원문부터 재생한 특징의 바이트 일치를 확인한다.

## 실측 결과

9개 GAT 학습이 893.5초(약 14.9분)에 정상 종료했다. 아래는 시드별 정확도를 평균한 값이
아니라, **3시드 예측 확률을 평균해 정답과 대조한 값**이다.

| 모델 | 원래 4,813쌍, 미응답 포함 | 공통 예측 4,743쌍 |
|---|---:|---:|
| old_full — 기존 학습 범위 복원 | 38.8144% | 39.3869% |
| augmented — 새 기사 추가 | **38.8541%** | **39.3852%** |
| no_content — 본문·감성 제거 | 38.8790% | 39.4194% |
| 원래 GNN | **39.6143%** | 39.5271% |
| 종목별 학습 빈도 기준선 | 39.2045% | 39.0993% |
| 시장별 다수 클래스 기준선 | 34.7993% | 34.7655% |

원래 모집단에서 새 기사 추가는 old_full 대비 +0.0397%p, 뉴스 제거 대비 −0.0249%p,
원래 GNN 대비 −0.7602%p다. 공통 예측 모집단에서는 old_full과 −0.0017%p 차이다.
미응답을 포함하면 거래일 내부 분모도 달라지므로 두 모집단의 차이는 단순 4,743/4,813배가 아니다.
**65% 미달이며, 원래 모델을 교체하지 않는다.** 기존 기사 수를 복원해 새 기사를 추가하는
이번 설정으로는 개선을 입증하지 못했다. GNN이나 뉴스 예측이 일반적으로 불가능하다는 결론도 아니다.

| augmented | 37.0914% | 37.3070% | 40.9748% | 40.0431% |

공통 4,743쌍에서 KOSPI 233거래일/NASDAQ 247거래일을 비교했다. old_full, no_content,
원래 GNN, 종목별 빈도와의 각 시장×기간 차이는 HAC lag5/20 모두 Holm 보정 p=1이다.
NASDAQ 1/3일에서 시장별 다수 클래스보다 +7.9849/+8.6121%p 높았고, 보정 p는

원래 GNN 또는 뉴스 제거 모델 대비 개선이라고 바꾸어 말하지 않는다.

`completion.json`, `validation_metrics.csv`, `coverage_adjusted_metrics.csv`,
`validation_comparisons.csv`, `selections.json`에 원수치를 보존했다.

- 원본·코드·준비 산출물 해시, 845,742개 기존 쌍의 완전 일치, 원래 평가 모집단 보존 확인.
- 기존 입력 28,421개를 다시 검사해 시점 부적합 1,048개 입력과 정답 3쌍 제외를 대조.
- 동결된 새 사건 원천의 정답 7,242개, 7개 그래프와 특징 캐시를 재검사.

- 9개 조기 종료 선택과 3시드 평균 일치, 평가지표 24행 독립 재계산: 최대 차이 **5.55×10⁻¹⁷**.
- HAC 40개와 시차별 Holm 20개 비교 재계산: 최대 통계 차이 **4.44×10⁻¹⁶**.

전체 기록은 `reload_verification.json`이다. 실행·수치의 일관성 검증이며, 사람 검수나
과거 법인 식별 인증, 새 기간 예측력 증명을 대신하지 않는다. 원래 모델·데이터는 보존했고,
새 test 예측·서비스 연결·커밋·push/MR은 수행하지 않았다.

## 후속 후보 — 이번 결과 확인 전 독립 코드 검토

1. **선택 기준부터 목표와 맞춘다.** `train_news_impact.loss_fn`은 방향 CE와 강도
   Smooth L1의 두 기간 평균을 기사별 동일 가중으로 학습한다. `train_target_news.fit_target`은
   같은 복합 val 손실이 최소인 모델을 선택한다. 사용자 목표인 거래일 동일 가중 방향 정확도와
   선택 기준이 다르다. 먼저 체크포인트 선택만 분리하고, 이후 시장·기간·거래일별 학습 가중치를
   별도 대조할 수 있다. 이 불일치가 지금 성능의 원인이었다고 확정하지 않는다.
2. **원천 시각·과거 기업·사건 주체를 검수한다.** 추출 건수를 더 늘리기 전에 보존된 기사
   ID/URL과 원수집 기록을 대조한다. 최초 발행/수정시각 계약, 역사적 별칭·법인 이력과 사람
   검수 정답은 로컬에 충분히 없다. 준비된 검수 자료와 자동 규칙을 인증 자료라고 부르지 않는다.
3. **현 데이터에서 기업 간 연결만 제거해 비교한다.** 현재 2023 그래프는 공동언급 32개,
   가격 상관 756개다. 같은 학습 자료·뉴스 특징에서 GAT의 기업 간 엣지만 제거하면 이 그래프의
   추가 효과를 분리할 수 있다. 과거 다른 데이터에서 수행한 연결 제거 결과로 대체하지 않는다.

세 후보 모두 기존 정답·4,813쌍·미응답 처리·65% 목표를 유지한다. 설정 탐색에는 학습 기간
내부 시간순 분할을 우선 쓰되, PCA 같은 학습 전처리도 해당 내부 학습 기간에서만 맞춰야 한다.
지금의 전 학습 기간 PCA를 그대로 쓴 내부 평가를 시간 누설 없는 평가라고 표현하면 안 된다.
이 항목은 후보이며 아직 실행하지 않았다. 어떤 변경도 65% 도달을 보장하지 않는다.
