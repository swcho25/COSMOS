# 주가 맥락을 추가한 뉴스 GNN 실험

2026-09-15. 기업별 문맥 GNN의 검증 정확도 39.09%만으로는 사용자 목표 65%에
미치지 못해, 뉴스 당시의 시장 상황이 도움이 되는지 추가로 검증한다.
이전 실험과 같은 직접 언급 기업, 가격 정답, 2023년 검증 구간을 유지한다.
새로운 독립 테스트 구간을 사용한 성능 입증이 아니다.

## 입력과 시간 경계

`market_context_features.py`는 각 기업 노드에 25차원 주가 맥락을 추가한다.

- 숫자 12개: 종목·실제 시장지수·시장 대비 수익률 각각 1/5/20거래일,
  종목·지수 20거래일 변동성, 종목 60거래일 고점 대비 하락폭.
- 위 12개 값 각각의 존재 여부 12개. 없는 가격을 채워 넣지 않는다.
- 사용한 마지막 종가부터 뉴스 이용 가능 시각까지 경과일 1개.

각 뉴스의 기존 `available_at`을 사용한다. 실제 거래소 종가 시각에 15분 수집 여유를
더한 시각이 `available_at` 이하인 마지막 거래일까지 사용한다. 미국 서머타임·조기 폐장과
한국의 과거 폐장 시각은 기존 거래소 달력 함수를 따른다. 당일 종가를 무조건 사용하는 방식이 아니다.
기존 정답은 이용 가능 시각 이후 첫 종가부터 향후 1/3거래일까지의 수익률로 그대로 둔다.

숫자 특징의 평균·표준편차는 입력 적격 학습 기사와 기업에서만 계산한다.
정규화 후 [-8,8]로 제한하고 결측은 0, 존재 표시는 0으로 넣는다.
경과일은 최대 30일에서 제한하고 7로 나눈다. 제외한 기사와 test에는 새 특징을 생성하지 않는다.

사용 파일은 기존 `data/prices_daily.parquet`와 v2의 실제 KOSPI/NASDAQ 지수 CSV다.
다운로드 시점에 보정·수정된 시계열일 수 있어, 당시 공급자가 실제 전송했던 원본 기록까지
재현하는 것은 아니다. 과거 그래프도 기존 스냅샷을 유지한다.

## 학습과 비교

| 실험군 | 뉴스 | 과거 주가 | GNN |
|---|---|---|---|
| news_price | 기업별 문맥과 감성 | 사용 | 3시드 |
| price_only | 텍스트·감성을 0으로 제거 | 사용 | 3시드 |

기존 `TargetNewsGAT`의 노드 입력에 기사별 주가 맥락을 연결한다.
두 모델의 구조와 설정은 같다. 직접 언급 라벨만 손실에 사용하며,
2층 GATv2, 은닉 64, dropout 0.15, AdamW 8e-4, weight decay 1e-3,
batch 24, 최대 30 epoch, patience 6을 고정한다. 각 시드의 검증 손실로
체크포인트를 고르고 3개의 확률을 평균한다.

입력·라벨 조건은 이전 실험과 동일하다. 검증 4,743쌍에 대해 price_only,
이전 target/pooled/no_content, 기존 GNN, 다수 클래스, 기업 통계, stage2를 비교한다.
시장 × 1/3일의 네 셀에서 거래일별 정확도를 동일 가중 평균한다.
뉴스+주가 대 8개 기준선 × 네 셀의 32개 차이에 HAC lag 5/20을 적용하며,
각 lag에서 Holm 보정한다. 뉴스 추가 이득은 특히 price_only와의 차이로 확인한다.

65% 목표의 주지표는 **원래 직접 검증 4,813쌍**이다. 입력 오류로 제외한 70쌍을
미응답/오답으로 포함한다. 원래 모집단과 유지 표본의 정확도가 모두 65%를 넘었는지 기록한다.
목표에 맞추기 위한 라벨 변경이나 결과에 따른 표본 제외는 하지 않는다.
모델을 자동 교체하거나 운영 서비스에 연결하지 않는다.

## 재현과 검증

출력은 `artifacts/news_market_context_20260915/`이며 이전 실험 폴더를 의존성으로 읽는다.
원본·코드·특징 해시를 저장하고 학습 전후 확인한다. prepare 출력 폴더는 새 경로여야 한다.

```powershell
$env:PYTHONUTF8='1'
$env:PYTHONUNBUFFERED='1'
AI/ner/.venv/Scripts/python.exe AI/graph/tests/test_market_context_features.py
AI/ner/.venv/Scripts/python.exe AI/graph/experiment_market_context.py --parent AI/graph/artifacts/news_target_experiment_20260915 --out AI/graph/artifacts/news_market_context_NEW --stage prepare
AI/ner/.venv/Scripts/python.exe AI/graph/experiment_market_context.py --parent AI/graph/artifacts/news_target_experiment_20260915 --out AI/graph/artifacts/news_market_context_NEW --stage train
AI/ner/.venv/Scripts/python.exe AI/graph/verify_market_context.py --experiment AI/graph/artifacts/news_market_context_20260915
```

가격 특징 테스트 5개가 통과했다. 미래 가격 변조 불변성, 15분 경계,
결측 비보간, 검증 구간이 학습 정규화에 영향을 주지 않는지,
기사별 가격 입력이 다른 기사의 예측으로 섞이지 않는지를 검사한다.

`verify_market_context.py`는 모든 가격 기준시각을 확인하고, 6개 원문–기업 쌍의
12개 가격 특징을 가격 비율로 독립 재계산한다. 6개 체크포인트를 CPU에 다시 읽고,
검증 예측 행과 전체 앙상블을 대조하며 통계 64개와 목표 점수를 별도로 재계산한다.

## 결과

6개 학습과 재로딩 검증을 완료했다. 특징 준비 13.3초, 학습·평가 569.3초가 걸렸다.

| 모델 | 유지 4,743쌍 정확도 | 원래 4,813쌍 정확도 |
|---|---:|---:|
| 기존 GNN | 39.53% | 39.61% |
| 기업별 뉴스만 target | 39.09% | 38.56% |
| 뉴스+주가 news_price | 39.16% | 38.65% |
| 주가만 price_only | 39.58% | 39.09% |

원래 모집단에서 새 모델의 제외 70쌍은 미응답/오답이다. 기존 모델은 원래 예측 전체를 사용했다.
유지 표본에서 뉴스+주가는 target보다 +0.066%p, price_only보다 -0.425%p였다.
기존 GNN 및 주가만 쓰는 모델 대비 전반적인 개선이나 뉴스의 추가 예측 이득을 확인하지 못했다.
KOSPI 3일은 주가만 쓰는 모델보다 -1.352%p였고 HAC lag20의 Holm p=0.03394로
열세였다(lag5에서는 보정 후 유의하지 않음). NASDAQ의 다수 클래스 대비 우위는 있었지만,
이를 더 강한 기준선 대비 개선으로 표현하지 않는다. 기존 후보를 유지한다.

**65% 목표 미달.** `completion.json`과 `reload_verification.json` 모두
`user_target_met=false`다. 검증 구간을 반복 사용한 연구 결과이며 새 test 예측은 만들지 않았다.

검증 결과:

- 가격 기준시각 39,728개 모두 뉴스 이용 가능 시각 이전의 허용된 마지막 종가와 일치.
- 6개 원문–기업 쌍의 가격 특징 독립 재계산 최대 차이 8.51e-9.
- 6개 체크포인트 CPU 재생 36개 예측의 최대 차이 8.94e-8.
- 전체 검증 예측의 행 정렬·3시드 앙상블 일치, 통계 64개 재계산 최대 차이 3.89e-16.
- 원본·코드·특징 해시 유지. 새 회귀 검사 5개 통과.

이전 기업별 문맥 실험까지 합쳐 이번 작업에서 GNN 15개를 학습·재생했다.
입력 정제, 기업별 문맥 보장, 직접 손실 집중, 주가 맥락 추가로도 현재 검증 정확도를
65%로 끌어올리지 못했다. 이 결과가 다른 모든 GNN 설계에서도 불가능하다는 증명은 아니다.

## 다음 개선에 필요한 데이터

검증 결과를 보며 같은 구간에 파라미터만 반복해서 맞추는 작업은 중단한다.
다음 데이터 개정은 아래 조건을 갖춘 별도 실험으로 진행해야 한다. 아직 수행하지 않았다.

1. 학습 기사에서 실적·수주·공시 등 기업 사건과 부수적 언급을 구분하고,
   사건이 실제로 해당 기업에 관한 것인지 사람 검수로 확인한다. 이번 100쌍 감사는 에이전트의 정성 검토다.
2. 추천 피드가 제거된 원문과 실제 발행시각·수집시각을 확보한다. 현재 날짜만 있는 기사의
   보수적 시각 처리로 즉각적인 가격 반응과 정답 창이 멀어지는 사례가 있다.
3. 위 기준으로 학습 기간의 고품질 기사를 확대하고, 정제 원문과 과거 기업 정체성으로
   그래프도 다시 검증한다. 결과가 좋았던 기사만 뽑거나 검증 표본을 줄이지 않는다.
4. 새로운 실험 설정을 고정한 뒤 이전에 보지 않은 후속 기간으로 확인한다.
   현재처럼 반복 확인한 2023년 점수만으로 배포 성능을 보증하지 않는다.

정답을 뉴스의 긍정/부정으로 바꾸면 별도 과제가 된다. 그 수치로 지금의
지연 수익률 3분류 목표 65%를 달성했다고 기록해서는 안 된다.
