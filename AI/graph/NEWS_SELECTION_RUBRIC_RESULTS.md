# 뉴스 선별 기준·평가 참고자료 교정 결과

2026-09-17 KST. **‘기업 관련성이 있다’는 AI 판정과 ‘주가예측 학습에 적합한 정답’을 분리했다.**
기준·검증 코드·개발 재판정·새 표본의 두 AI 참고판정을 만들었다.
모델 성능 향상이나 믿을 수 있는 사람 정답집 완성을 입증한 작업은 아니다.

## 1. 바로잡은 판정 구조

`news_selection_rubric_v1.md`에 아래6축을 고정하고 `news_selection_rubric.py`가 검증한다.

1. 대상 기업의 사건인지: 직접/간접 관련, 단순언급, 불명
2. 같은 대상 사건에 관한 새 정보인지: 새 발표, 새 후속 정보, 기존 배경, 불명
3. 구체적 경제 변화인지: 구체 변화, 일반 비교·배경, 없음, 불명
4. 특정 증권 사건이 대상 종목에 맞는지
5. 원문상 사실 서술인지, 보도·계획·전망인지
6. 경제적 크기·범위에 관한 근거가 있는지

다른 회사의 오늘 발표 시점과 대상 기업의 과거 실적 문장을 합치지 않는다.
‘최근’과 기사 날짜만으로 새 발표를 확정하지 않는다. 원문에 현재 발표가 명확하면
세계 최초 보도 여부까지 이 의미 판정 단계에서 요구하지는 않는다.
단순언급/경제정보 없음/기존 배경뿐인 경우와 근거가 모자라 재검토하는 경우를 나눈다.

신상품·전망 기사도 구체적 새 정보가 있으면 의미상 후보가 될 수 있다.
중요성이 미확정이라는 이유만으로 무관하거나 주가가 움직이지 않는다고 단정하지 않는다.
모든 판단은 **같은 대상 사건**을 기준으로 하고 축별 정확한 원문 인용을 보존한다.

`candidate`는 의미상 후보일 뿐이다. 실제 이용 가능 시각·종목 대응·중복 사건·가격 구간·
가격 품질을 확인하기 전에는 `training_readiness=pending_checks`,
`ready_for_gnn_training=false`다. AI 판정은 `human_gold=false`, `usable_as_training_gold=false`다.

## 2. 기존 ‘채택19건’ 재판정

기존32건 전체를 새 기준으로 별도 재검토했다. 이는 **사후 AI 개발 검토**이며
기존 참고판정이나 사용자의 원래100선택을 덮어쓰지 않았다.

| 기존 AI 채택19건의 새 상태 | 건수 |
|---|---:|
| 의미상 후보 | 14 |
| 재검토 | 4 |
| 해당 대상 사건의 학습 후보에서 제외 | 1 |

14건을 새로운 확정 정답14건이라고 부르면 안 된다. 가격 영향·학습 적격성을 검증한 수가 아니다.
32건 전체의 새 상태는 후보14 / 재검토8 / 제외10이다.
기존 제외9건은 제외로, 기존 보류4건은 재검토로 남았다.

| 달라진 대상 사례 | 새 개발 판정 | 이유 |
|---|---|---|
| Netflix / Disney+ 실적 기사 | 제외 | 대상의 기존 가입자 감소 등을 배경으로 재인용. Disney 발표 시점을 Netflix의 신규 발표로 옮기지 않음 |
| Amazon / Apple 실적 기사 | 재검토 | 실적 실망·주가 하락이라는 짧은 비교만으로 새 세부 경제 변화를 확정하지 않음 |
| 두산 / 우선주 유동성 계약 | 재검토 | 발행인 관련성과 해당 증권·대상 종목 대응을 구분 |
| Apple / 자율주행차 발언을 언급한 시장 해설 | 재검토 | 이미 발생한 주가 움직임의 설명이며 발언 공개시점·구체적 변화가 불명 |
| Apple / iMessage 기능 보도 | 재검토 | 원문이 구체적 변경 내용·출시 시점이 공개되지 않았다고 설명 |

삼성생명 신상품 기사는 출시·상품 구조에 새 정보가 있어 의미상 후보로 남지만
중요성 근거는 미확정이다. 모든 상품 기사를 일괄 제외하는 규칙으로 바꾸지 않았다.
키움증권·한국전력 등도 개발 검토자의 의미상 후보이지 실제 주가 영향 정답으로 승격하지 않는다.

개별32건과 이유는 실험 폴더의 `DEVELOPMENT_REVIEW.md`, 원문 인용은 `development_reviews.jsonl`에 있다.
같은 기준의 다른 검토자는 일부 경계 사례에 이견을 낼 수 있으며, 아래 새 표본에서 그 한계를 확인했다.

## 3. 아직 보지 않은32건의 판정 안정성 확인

규약·코드를 `plan.json`으로 먼저 동결한 뒤 과거검토686기사와 가격예측 val/test11969기사를
ID·본문·URL로 배제했다. 국내 출처16·해외 출처16, 2020~2022년, 본문200~6000자 표본이다.
원문은 그대로 보존했다. 두 AI가 **같은32건 전체**를 각각 읽고 상대의 해당 기사 판정과 모델 출력을 보지 않았다.

| 항목 | 결과 |
|---|---:|
| A: 후보 / 제외 / 재검토 | 11 / 8 / 13 |
| B: 후보 / 제외 / 재검토 | 12 / 5 / 15 |
| 후보·제외·재검토의 파생 상태가 같은 기사 | 25/32 |
| 여섯 축 값이 모두 같은 기사 | 9/32 |
| 전축 일치한 후보 / 제외 / 재검토 | 6 / 1 / 2 |
| 축 하나 이상에 이견이 있는 기사 | 23/32 |

이는 **일치 수이며 정확도가 아니다.** 단순한 최종 상태는 같아도 신규성이나 주장 상태의
세부 분류가 다른 경우가 있다. 상태 자체가 다른7건과, 상태는 같지만 세부축이 다른16건을 구분한다.
전축 일치 후보6건도 사람이 검증한 정답이나 학습 투입 확정이 아니다.

| 축 | 값이 일치한 건수 |
|---|---:|
| 대상 귀속 | 29/32 |
| 신규성 | 16/32 |
| 경제적 내용 | 27/32 |
| 증권 범위 | 31/32 |
| 주장 상태 | 25/32 |
| 중요성 근거 | 30/32 |

**신규성은 아직 안정적인 정답으로 쓰기 어렵다.** 불일치16건 중4건은 새 발표/새 후속정보 사이의
구분 차이였고, 나머지는 시점 불명·기존 배경과 새 정보 판단의 차이였다.
시장 개장 전 실적 요약, 취임 회고에 섞인 현재 계획 등이 경계 사례다.
기사에서 여러 사건을 골랐을 수 있으므로 축 값 일치 자체가 같은 사건·근거 해석의 일치를 증명하지도 않는다.

새 결과를 보고 규칙을 완화하거나 판정을 맞춰서 합의율을 높이지 않았다.
23건은 `disputed`로 보존하고 자동 정답 편입을 막았다.
각 판정과 근거는 `PAIRED_REVIEW.md`, `paired_evaluation/paired_reviews.jsonl`에 있다.

## 4. 학습 적격성·검토 노출의 한계

새32건의 시각 메타데이터는 시간대 미검증 시각16건 / 날짜만 있는 경우16건이었다.
이는 사용 불가능하다는 뜻이 아니라, 정확한 공개시각 또는 보수적인 날짜 정밀도 정책을
별도로 확인해야 한다는 뜻이다. 이번에는 가격·수익률을 읽거나 라벨 구간을 만들지 않았다.

두 검토자는 같은 모델 계열의 AI여서 공통 오류를 낼 수 있다. B는 작성 마지막에
별도 개발32건 작업의 완료 메시지(파일 경로·SHA·집계 수)를 자동 수신했다.
개발 사례별 판정이나 상대 A의 새32건 판정은 열람하지 않았으나, 완전한 외부정보 차단이라고 표현하지 않는다.
이 노출 범위는 `review_blinding_notes.json`에 기록했다.

`human_review_queue.jsonl`에는 AI 답이 포함되어 있어 독립 사람 정답 수집 화면에 그대로 노출하면 안 된다.
그 목적으로는 AI 답이 없는 전체32건 원문 `human_blind_inputs.jsonl`을 별도로 보존했다.
사람 검토를 수행한 것은 아니며, 사용자에게 이 파일의 검토를 이번 작업 조건으로 요구하지 않는다.
