# 외부 서비스 정보 (초안)

저장소의 [`docs/infrastructure-design.md`](../docs/infrastructure-design.md), [`docs/CICD.md`](../docs/CICD.md)에서 확인한 서비스와 제출 전 확인이 필요한 항목입니다. 설계 문서에 나온 서비스가 실제 운영에 모두 사용 중인지는 팀 담당자가 확인해야 합니다. 계정 ID·비밀번호·API 키·토큰은 이 파일에 기록하지 않습니다.

| 서비스 | 프로젝트에서 확인한 용도 | 가입·설정·인계 시 확인할 내용 |
| --- | --- | --- |
| SSAFY GitLab | 소스 저장소, MR 및 Jenkins 체크아웃 | 프로젝트 접근 권한, Jenkins 읽기 전용 Deploy Token 관리 담당자 |
| AWS | Hadoop Worker 3대와 EBS 저장소 설계 | 사용 중인 계정·리전·인스턴스·볼륨·IAM 역할, 종료·인계 일정 |
| Tailscale | SSAFY Master와 AWS Worker의 사설망 연결 설계 | Tailnet 관리 계정, 장치 승인, MagicDNS·접근 규칙 |
| OpenDART / SEC EDGAR | 국내·미국 공시 수집 설계 | 실제 사용 API와 발급 계정, 호출 제한, 키 보관 위치 |
| Yahoo·네이버 등 뉴스/주가 제공처 | 뉴스 및 시세 수집 설계 | 실제 사용처, 이용 조건, API 또는 크롤링 방식, 장애 시 대안 |
| 인증서 발급 서비스 | `certbot`을 통한 HTTPS 인증서 발급·갱신 | 도메인 관리 담당자, 갱신 상태와 알림 경로 |
| 이메일 발송 서비스 | 인증 메일 기능에 필요한 발송 수단 | 실제 제공처, SMTP/API 설정, 발신 주소, 키 보관 위치 |

## 인계 절차

1. 운영 중인 서비스만 남기고 각 서비스의 관리 담당자와 가입·발급 절차를 채웁니다. 설계만 존재하고 사용하지 않는 항목은 삭제하거나 미사용으로 표시합니다.
2. 코드·배포 설정에서 필요한 변수명과 설정 파일 경로를 확인합니다. 실제 비밀값은 저장소 밖의 접근 제한된 수단으로 전달합니다.
3. 도메인, API 호출 제한, 과금, 만료일, 데이터 이용 조건을 확인합니다.
4. 서비스별 최소 동작을 재현해 계정 인계가 완료됐는지 확인합니다.

## 팀 확인 항목

- [ ] 소셜 로그인 사용 여부와 제공처·콜백 URL 확인
- [ ] 실제 API 제공처와 API 키 발급 방법 확인
- [ ] 이메일 발송 서비스의 실제 제공처·설정 확인
- [ ] AWS 및 Tailscale 운영 계정·권한·비용·종료 일정 확인
- [ ] 인증서·도메인 관리 담당자 확인
