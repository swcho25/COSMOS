# 시연 시나리오 (초안)

확인한 서비스 주소: https://j15c205.p.ssafy.io/ (2026-09-28 화면 기준). 화면 구성과 데이터는 배포·스냅샷 갱신에 따라 바뀔 수 있으므로 발표 직전에 같은 순서로 리허설합니다. 아래 동선은 로그인 없이 볼 수 있는 공개 화면을 기준으로 합니다.

| 순서 | 화면 | 조작 위치와 실행 방법 | 보여 줄 내용 |
| --- | --- | --- | --- |
| 1 | 전체 은하 `/` | 상단 메뉴 `전체 은하`를 누릅니다. 로딩이 끝나면 은하 범위가 `전체 은하`인지 확인합니다. | 기업 관계를 은하 형태로 시각화한 기본 화면과 공개 스냅샷 시각 |
| 2 | 전체 은하 조절판 | 화면의 `조절판`에서 `공급`, `투자·지분`, `협력`, `경쟁` 관계 종류를 차례로 선택합니다. `은하` → `평면` 또는 `정렬`을 눌러 배치를 비교합니다. | 관계 종류와 배치 방식에 따라 연결선·기업 위치가 달라지는 모습 |
| 3 | 전체 은하 기간·필터 | `산업` 필터에서 한 산업을 선택하고, `관계선 기준`의 `1M`, `1Y`, `10Y`를 비교합니다. 필요하면 `초기화`를 누릅니다. | 산업과 기간에 따른 관계망 변화 |
| 4 | 기업 `/companies` | 상단 `기업`을 누릅니다. 목록 위 검색칸에 시연할 기업명을 입력하고, `시장`·`산업` 필터를 적용한 뒤 기업 행을 선택합니다. | 기업의 시장·산업·연결 관계 수와 미리보기. 미리보기의 `은하에서 관계 보기`를 눌러 관계망으로 이동할 수 있습니다. |
| 5 | 뉴스 `/news` | 상단 `뉴스`를 누릅니다. `산업 필터` 또는 `뉴스 검색`으로 기사를 찾고 왼쪽 목록에서 기사 한 건을 선택합니다. | 선택 뉴스의 연결 기업, 긍정/부정, 근거 문장 수, 분석 신뢰도와 영향도가 큰 기업 |
| 6 | 뉴스 원문 | 선택한 뉴스의 `원문 보기`를 누릅니다. | 분석 결과의 원문 출처 확인. 외부 페이지가 열리므로 발표 환경의 팝업·네트워크를 점검합니다. |

## 발표 전 준비

- [ ] 실제 데이터가 있는 기업·뉴스를 골라 제목과 검색어를 기록하고, 화면별 소요 시간을 맞춥니다.
- [ ] `전체 은하`의 최신 스냅샷 로딩과 뉴스·기업 목록 표시를 확인합니다.
- [ ] 로그인·관심 기업·커뮤니티 기능을 발표한다면 별도 테스트 계정과 상세 조작 순서를 팀이 추가합니다.
- [ ] 조작 중 데이터가 없는 경우를 대비해 다른 기업·기사 후보를 준비합니다.
- [ ] 시연 화면 캡처가 필요하면 최종 리허설에서 촬영하고 이 문서에 첨부합니다.
