# 시연 시나리오

서비스 주소: https://j15c205.p.ssafy.io/ (2026-09-28 화면 기준, 공개 스냅샷 2026-09-22 09:00, 기업 202개). 배포나 스냅샷이 갱신되면 화면과 데이터가 바뀔 수 있으니 발표 직전에 같은 순서로 리허설합니다.

상단 메뉴: `전체 은하` · `뉴스` · `기업` · `커뮤니티`, 오른쪽 끝에 `로그인` · `회원가입`.

## A. 공개 화면 (로그인 없이)

| 순서 | 화면 | 조작 위치와 실행 방법 | 보여 줄 내용 |
| --- | --- | --- | --- |
| 1 | 전체 은하 `/` | 상단 메뉴 `전체 은하`를 누릅니다. 로딩이 끝나면 은하 범위가 `전체 은하`인지 확인합니다. | 기업 관계를 은하 형태로 시각화한 기본 화면과 공개 스냅샷 시각 |
| 2 | 전체 은하 조절판 | 화면의 `조절판`에서 관계 종류 `공급`, `투자·지분`, `협력`, `경쟁`을 차례로 선택합니다. 배치를 `은하` → `평면` 또는 `정렬`로 바꿔 비교합니다. | 관계 종류와 배치 방식에 따라 연결선·기업 위치가 달라지는 모습 |
| 3 | 전체 은하 기간·필터 | `산업` 필터에서 산업 하나를 고르고, `관계선 기준`의 `1M`, `1Y`, `10Y`를 비교합니다. 되돌릴 때는 `초기화`. | 산업과 기간에 따른 관계망 변화 |
| 4 | 기업 `/companies` | 상단 `기업`을 누릅니다. 목록 위 검색칸(`기업명·영문명·종목코드`)에 기업명을 입력하고, `전체 시장`·`전체 산업` 드롭다운으로 거른 뒤 기업 행을 누릅니다. 정렬은 `시가총액순` / `기업명순`, 보기 전환은 `목록` / `투자·지분 관계`. | 기업별 시장·산업·연결 관계 수·최고 관계 점수와 미리보기. 미리보기의 `은하에서 관계 보기`를 누르면 해당 기업 중심 은하로 이동합니다. |
| 5 | 뉴스 `/news` | 상단 `뉴스`를 누릅니다. `산업 필터` 또는 `뉴스 검색`으로 기사를 찾아 왼쪽 목록에서 한 건을 누릅니다. | 선택 뉴스의 연결 기업, 긍정/부정, 근거 문장 수, 분석 신뢰도, 영향이 큰 기업 |
| 6 | 뉴스 원문 | 선택한 뉴스의 `원문 보기`를 누릅니다. | 분석 결과의 원문 출처. 외부 페이지가 새로 열리므로 발표 PC의 팝업 차단·네트워크를 미리 확인합니다. |
| 7 | 커뮤니티 `/community` | 상단 `커뮤니티`를 누릅니다. 오른쪽 위 `전체 산업` 드롭다운으로 산업을 고르고, 댓글 하나를 누릅니다. | 모든 기업 댓글을 최신순으로 모은 피드. 댓글을 누르면 그 기업을 은하에서 바로 보여 줍니다. |

## B. 로그인 기능

| 순서 | 화면 | 조작 위치와 실행 방법 | 보여 줄 내용 |
| --- | --- | --- | --- |
| 8 | 회원가입 | 오른쪽 위 `회원가입` → `이메일` 입력 → `인증 코드 받기` → 메일로 온 코드 입력 → `닉네임`(2~30자), `비밀번호`(8~64자, 영문·숫자 포함), `비밀번호 확인` → `가입하고 시작하기` | 이메일 인증 가입. 비밀번호 조건 체크(`8자 이상`, `영문 포함`, `숫자 포함`)가 입력하는 동안 표시됩니다. 인증 메일은 Gmail SMTP로 발송되며 코드는 5분간 유효합니다. |
| 9 | 로그인 | 오른쪽 위 `로그인` → 이메일·비밀번호 입력 | 로그인 후 오른쪽 위에 사용자 메뉴(관심 기업·스크랩 수 표시)가 나타납니다. |
| 10 | 관심 기업 | `기업` 목록 오른쪽 끝 `관심` 열의 ☆를 누릅니다. 이후 오른쪽 위 사용자 메뉴의 관심 기업·스크랩 항목(`/me/watchlist`)에서 확인합니다. | 관심 기업 등록·해제, 스크랩한 뉴스 모아 보기 |
| 11 | 기업 댓글 | `은하에서 관계 보기`로 들어가 은하에서 기업을 누르면 열리는 기업 패널에서 댓글을 작성합니다. `커뮤니티` 피드에 새 댓글이 맨 위에 나오는지 확인합니다. | 커뮤니티 연동 |

발표용 계정은 운영 서버에서 미리 가입해 둡니다 (발표 중 인증 메일 수신이 늦어질 수 있습니다). `exec/DB_DUMP.md`의 덤프를 복원한 환경에서는 `demo4@example.com` ~ `demo8@example.com`, 비밀번호 `CosmosDemo2026`으로 바로 로그인할 수 있습니다. 이 계정은 덤프에만 있고 운영 서버에는 없습니다.

## 발표 전 준비

- [ ] 데이터가 충분한 기업(예: 삼성전자, SK하이닉스, Nvidia, Apple)과 기사 제목·검색어를 정해 두고, 화면별 소요 시간을 맞춥니다.
- [ ] `전체 은하`의 스냅샷 로딩과 뉴스·기업 목록 표시를 확인합니다.
- [ ] 발표용 계정 로그인, 관심 기업 등록, 댓글 작성을 한 번씩 해 봅니다. 테스트 댓글은 리허설 후 지웁니다.
- [ ] 데이터가 비는 경우에 대비해 다른 기업·기사 후보를 준비합니다.
- [ ] 수집 파이프라인은 현재 멈춰 있다(2026-09-28). 화면의 데이터는 2026-09-22 스냅샷 기준으로 고정됩니다.
